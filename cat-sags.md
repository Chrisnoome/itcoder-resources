# CAT IEB SAGs 2025 - full reference

**Source:** IEB *Computer Applications Technology (CAT) Subject Assessment
Guidelines (SAGs)*, updated November 2023 -
`sources/cat/ieb/IEB_CAT_SAGS_2025.pdf`, section 5 of the IEB's National
Senior Certificate Handbook (pages numbered 5/1 to 5/72). Extracted with
`pdftotext -layout`; the two analysis grids (Appendices G and H) were read
as rendered pages, because their column headings are rotated and the text
extractor interleaves them.

**Which year it is for.** The cover page says "Implementation Grade 12
**2024**"; every page footer says "IMPLEMENTATION DATE: GRADE 12, **2025**",
and the IEB files it as "CAT SAGS 2025". The 2025 footer is the one to
trust - it is on all 72 pages and matches the file name - but the
contradiction is worth a check with the IEB before anything is published
against it ([course-plan.md](course-plan.md) §5, question 12).

**What this file is for:** a token-cheap reference to check syllabus
wording, weighting or a paper's shape without re-opening the PDF - the IEB
twin of [caps.md](caps.md). A faithful, cleaned transcription of the SAGs'
own text, not a teaching document.

**Scope - what's in and what's left out:**

- **In:** sections A-C (means of assessment, requirements, both papers'
  structure and weighting, PAT, SBA, moderation); the two analysis grids'
  targets (Appendices G, H); the cognitive-level table (Appendix I); the two
  alternative tasks (Appendices J, K); **the whole content list - Appendix L
  (theory) and Appendix M (practical), Grades 10-12**; and the shape and
  mark split of the PAT rubric (Appendix N).
- **Out:** the administrative forms - Appendices A-F (consolidation,
  declaration, record of marks, moderation checklist, letter from the
  principal, evidence of moderation) - and the blank rows of the grids. The
  PAT rubric's full band descriptors are summarised, not reproduced; go back
  to the PDF (pages 5/57-5/72) to mark a PAT against it.

**How the IEB differs from CAPS, in one breath:** the same six CAPS topics,
but **the theory paper is systems-heavy** (40% of it) where CAPS spreads its
marks evenly, and **the practical paper is 180 marks, not 150**, with a
named 20-mark file-and-folder-management block. The IEB writes its own
content list rather than a term plan, so a place in the SAGs is "Grade 11,
Internet and Network Technologies" with no term attached. Databases and HTML
start in Grade 11 (CAPS teaches basic HTML in Grade 10); presentations are
Grade 10 and the PAT only. **The IEB's PAT allows a free choice of fourth
package** and is marked out of 170.

**The SAGs point at CAPS for content.** Both "details of the examination"
notes say the content assessed is "as described in Curriculum and Assessment
Policy Statement (CAPS) Computer Applications Technology - Section 3.
Department: Basic Education Republic of South Africa (2011, Updated 2012)" -
that is, **the original 2011 CAPS Section 3, not the 2024 amendment**. The
SAGs' own Appendices L and M then give a fuller, differently organised list
which goes well beyond it (Windows Settings by name, Excel's `XLOOKUP`,
pivot tables, Access input-mask characters). Where the two disagree,
Appendices L and M are what the IEB examines.

## 1. Means of assessment

| Component | Time | Raw | Counts |
|---|---|---|---|
| **Paper 1 (Practical)** | 3 hours | **180** marks | 100 |
| **Paper 2 (Theory)** | 3 hours | **150** marks | 100 |
| **Practical Assessment Task (PAT)** | through the year | **170** marks | 100 |
| **School Based Assessment (SBA)** | through the year | 100 | 100 |
| | | | **400** |

Both papers are externally set, externally moderated, and written in Grade
12. Paper 1 is **administered internally and marked externally**; Paper 2 is
externally marked.

### Paper 1 - practical (180 marks, 3 hours)

Assesses the practical skills of Solution Development: **word processing,
spreadsheets and databases, and creating a simple web page using HTML and a
text-based HTML editor**. **Presentations are assessed only in the PAT, not
in the examinations.** Skills are assessed **in an integrated manner based on
real-life scenarios**; problem solving and aspects of **computer management**
form part of the application questions. The whole paper runs off one
scenario.

| Content area | Marks / 180 |
|---|---|
| System Technologies - File and Folder Management | 20 ±5 |
| Solution Development - Word Processing including integration | 50 ±5 |
| Solution Development - Spreadsheet including integration | 50 ±5 |
| Solution Development - Database including integration | 40 ±5 |
| Solution Development - Web Development (HTML Design) | 20 ±5 |

Cognitive levels: **lower order (routine procedures, rote learning) 30% /
middle order (multi-step procedures) 40% / higher order (problem solving)
30%.**

**What is supplied:** an information sheet with HTML tags, for the web
development question; an **MS Access Input Mask List**, for the database
question; plus anything the DBE information sheet supplies. **No large
amounts of data entry** - data is retrieved from the data disk or imported
from a text file, word processing document, database table or spreadsheet.

**What the school must have installed:** the full package (word processor,
spreadsheet and database) **including wizards and help**; a text editor
(Notepad, WordPad or Notepad++) for the HTML; an Afrikaans spell check for
Afrikaans-medium candidates. **Minimum: Microsoft Office 365 (desktop) and
Windows 10.**

### Paper 2 - theory (150 marks, 3 hours)

All theory, including elements of Solution Development (the application
packages and file management). A section assesses understanding of the
technologies studied so as to make informed decisions in a real-life
end-user scenario, from choices of technology to its responsible use.

| Content area | Marks / 150 |
|---|---|
| System Technologies | **60 ±3** |
| Internet and Network Technologies | 30 ±3 |
| Information Management | 15 ±3 |
| Social Implications | 15 ±3 |
| Solution Development | 30 ±3 |

| Section | Questions | Description | Marks |
|---|---|---|---|
| **A** | 1 and 2 | Short questions, aligned to all the topics | ~25 |
| **B** | 3 | System Technologies | ~25 |
| | 4 | Internet and Network Technologies (Internet and WWW, e-communication, network technologies) | ~15 |
| | 5 | Information Management - **"in particular, using Input, Processing and Output (Algorithms) to solve a problem"** | ~10 |
| | 6 | Social Implications (impact of ICTs on society and health; social, legal, ethical, security and environmental issues) | ~10 |
| | 7 | Solution Development - the knowledge and understanding that supports the practical application of skills, i.e. the theoretical concepts behind the practical use of the applications | ~15 |
| **C** | 8 and 9 | Integrated scenario - one scenario, aligned to all the topics; making informed decisions in a real-life end-user scenario | ~50 |

The SAGs adds: *"Note: This does not total 150 as all topics overlap into the
Short Questions and Integrated Scenario."* (The listed figures come to 150,
but they are read as approximations spread across sections.)

Cognitive levels: **lower order (knowledge/remembering) 30% / middle order
(understanding, applying to a **known** scenario) 40% / higher order
(analysing, evaluating, creating, applying to an **unknown** scenario)
30%.**

**Content to be covered:** because the content progresses conceptually
across the grades, Grade 10-12 content and skills are assessed in the
external papers at the end of Grade 12.

### The PAT (100 of the 400 marks, "25% of the overall Grade 12 assessment")

An analysis of the learner's individual interaction with information and the
way they present it, finally as a number of documents communicating a
solution in an integrated manner. It exists so learners can show their skill
with **word processing, spreadsheet, database and a fourth package of their
own choice**; because the fourth package differs from school to school, it
is assessed **only** in the PAT, never in the final practical paper.

Requirements and assessment criteria are supplied; the PAT is **internally
marked and externally moderated**. The learner chooses the task or topic with
the teacher's approval. Two further IEB documents govern it: *CAT - Grade 12
- IEB PAT Task Guidelines* (on the IEB website) and the *PAT Assessment
Tools* (Appendix N; see §6).

### School Based Assessment (25% of the NSC mark)

| Component | Description | Mark |
|---|---|---|
| Test 1 / Exam | Standardised **theory** test OR mid-year theory paper - theory topics (hardware, software, networking, legal, ethical, security, safety) | 17.5 |
| Test 2 / Exam | Standardised **practical** test OR mid-year practical paper - Solution Development, applying integrated word processing, spreadsheet, database and web development skills | 17.5 |
| Task / Test | **Alternative assessment** OR a test (theory, practical or integrated) | 15 |
| Exam P1 | Grade 12 preliminary examination Paper 1 | 25 |
| Exam P2 | Grade 12 preliminary examination Paper 2 | 25 |
| | **Total** | **100** |

- **Minimum time for any test or task: 45 to 60 minutes** (the later note in
  the same section says a test "should cover a substantial amount of content
  and the duration should be at least 60 minutes"; it must not be a series of
  small tests).
- Each test and examination must reflect the **30:40:30** level division.
- Every test, task and examination in the SBA must be moderated by a teacher
  in the school or the cluster.
- **The tests and prelim papers must include an analysis grid** (§5).
- Learners collate their own SBA evidence through Grade 12 and should be told
  the requirements towards the end of Grade 11. Schools must be able to
  produce every learner's SBA evidence for the IEB or Umalusi - which may
  include **Grade 11 SBA work** if Umalusi asks for it.

## 2. Moderation

- **Regional:** the school gives the Regional Moderator the PAT and SBA
  results for every candidate, electronically, **in rank order**. The RM
  picks a **10% sample of PATs across the range of marks, minimum 5**.
  Electronic submission is allowed by arrangement. The teacher presents an
  Educator's File, the 10% sample of PATs, and (if the IEB asks) 10% of
  learners' SBA files.
- **National:** if files are called up after regional moderation, the
  completed Appendix D goes in the Educator's File signed by both teacher and
  RM. **If a school is called for national moderation, every candidate's PAT
  file must be submitted.** Where there is no appointed RM, Appendix D is not
  required. The national committee may make motivated recommendations to
  change marks.
- The Educator's File holds, in order: a labelled cover, Appendix D, Appendix
  C (record of marks, electronic), Appendix E (letter from the principal),
  copies of every test and exam, the assessment tools and marking guidelines,
  **evidence of analysis for the prelims and tests as a minimum**, the
  moderation list, evidence of moderation, the PAT description and assessment
  tools, and **two CDs/DVDs** labelled "SBA" and "PAT" holding every
  learner's work in a folder named with their examination number.
- Learner files (SBA and PAT) hold a labelled cover, Appendix A, Appendix B
  (declaration, signed by learner and teacher), the scripts or printouts, and
  the assessment tools showing where and why marks were deducted. **There must
  be a mark or comment on the actual script or printout.**

## 3. Cognitive levels (Appendix I)

| | Lower order | Middle order | Higher order |
|---|---|---|---|
| **Theory** | Knowledge / remembering | Understanding / applying | Analysing / evaluating / creating |
| **Practical** | Routine procedures | Multi-step procedures | Evaluation and problem solving |
| **Bloom** | Knowledge, Comprehension | Application | Analysis, Synthesis, Evaluation |
| **Weight** | 30% | 40% | 30% |

- **Knowledge** - information gathering: retrieving, recalling or recognising
  from memory; producing definitions, facts or lists.
- **Comprehension** - confirming: constructing meaning from different types
  of function, written or graphic; translating, interpreting, comparing,
  contrasting.
- **Application** - making use of knowledge in situations where learned
  material is used, through products like models, presentations, interviews
  and simulations; translating knowledge into a **familiar** context.
- **Analysis** - taking apart: breaking concepts into parts and working out
  how they relate; differentiating, organising, attributing; seeing patterns,
  recognising hidden meanings, inferring causes, predicting consequences.
- **Synthesis** - putting together: reorganising elements into a new pattern
  or structure; using old ideas to create new ones, generalising from given
  facts, relating knowledge from several areas, **translating knowledge into
  an unfamiliar context**.
- **Evaluation** - judging outcomes against criteria and standards;
  comparing and discriminating between ideas, making a choice on a reasoned
  argument, verifying the value of evidence, recognising subjectivity.

**Theory question stems, by level** (the SAGs' own lists):

| Lower | Middle | Higher |
|---|---|---|
| Choose the best description; Give appropriate term; Identify; List; Name; Provide definitions; Select appropriate answer; State true or false; What; Will; Describe; Discuss the term; Explain | Advantages; Conclude; Disadvantages; Examples; Identify where; Identify; Motivate why; Suggest; Support the recommendation; Why | Argue; Compare; Determine; Discuss how; Discuss the importance of; Explain; Generate; Give/list tips; How could you tell ...?; Justify; Predict; Propose solutions; Provide reasons; Recommend; Suggest; Why is it important ...? |

**Practical question stems, by level:**

| Lower | Middle | Higher |
|---|---|---|
| Rename; Move; Wrap the headings; Format; Resize; Insert a comment/column; Hide; Delete; Exclude; Adjust; Use the data; Show all the formulas; Replace the words; Activate protection; Merge; Split; Edit according to the editing symbol indicated; Print only | Insert/apply a function or formula; Convert | Arrange the data; Construct a formula or function; Create a named range; Design a chart/graph; Import; Export; Generate a Lookup; Devise input; Plan a query; Group the report; Process a mail merge; Merge the form letter |

*(The middle-order practical row is short in the source - only two stems -
and several of the "lower" stems, such as "Show all the formulas", would
plainly be routine. Treat the practical stem table as indicative.)*

## 4. Alternative assessment tasks (Appendices J and K)

Either of these may replace the SBA's Task/Test (15 marks). Both need a
detailed, descriptive brief with deadlines and structure, and both the task
and its rubric must be moderated.

### Appendix J - Theory Task 1: "set up a company's technology" (60 marks)

Scenario: you and a few peers start a company in a small rented building,
with **R200 000** to set up the technology and at least five employees who
need workstations with Internet access. The learner picks a relatable topic
with the teacher's approval - a gym club, a school CAT lab, a grocery store,
a bank branch, a doctors' practice, a design or video studio. **Individually
or in a pair.**

| Step | What | Marks |
|---|---|---|
| 2 | Company details - a summary of the business, and a list of technical requirements (hardware and software) | 20 |
| 3 | Budget - **in a spreadsheet, embedded in the final network proposal**; two quotes for all hardware and software, compared, one chosen and justified, its figures added to the budget | 10 |
| 4 | Floor plan of the office, with the layout of devices | 6 |
| 5 | Network plan - data transfer medium, logical topology, media access method, speed of data transfer and protocol, all justified; how the devices connect; naming the devices; the responsibility of each | 10 |
| 6 | Internet connection - the type of connection, the ISP and package | 4 |
| - | Bonus work - what makes this network stand out | 5 |
| - | Group work (leave out if done individually): division of work 2 + individual contribution 3 | 5 |

The rubric bands each row (for example, "list of technical requirements": 0-3
unclear or unjustified, 4-9 a basic list with errors, 10-15 a concise,
complete list with full and justified reasons).

### Appendix K - Practical Task 2: a survey, processed (75 marks)

An electronic survey is sent out, the responses collected, and the results
processed into a solution for a scenario. **Mail merging, electronic forms in
a word processor and importing of data must form part of it.** Suggested
topics: free first-year university education, school uniform, a census
question (water delivery, electricity costs), friends' interests.

| Step | What | Marks |
|---|---|---|
| 2 | An **online form e-mailed to at least 30 people** and returned, with proof of the e-mail conversations. Minimum fields, each with a stated criterion: Name (title case, max 60 letters), Surname (title case, max 50), Age (value, max 2 digits), Date of Birth (`MMMM-yy-dd`), a list box, a drop-down box, an option button or tick box, Contact numbers (number with default text), Gender (M or F). Must use appropriate fonts and sizes, a page border, tab stops, automatic numbering or bullets, and a table; **protected with editing restrictions and a generic password** | 24 |
| 3 | Capture the data in a spreadsheet using advanced skills (merging, shading, text wrapping) and at minimum SUM, AVERAGE, MAX, MIN, COUNT formulas, IF statements and VLOOKUP; one suitable graph with a title, X and Y axes, results above the bars and **an image used for the bars** | 20 |
| 4 | A merge document thanking the respondents, **importing the spreadsheet data**, with the graph linked (not pasted) so it updates; drop caps, formal letter layout, an appropriate font, merge fields for name, surname and contact number, and a thank-you image | 29 (the rubric totals 31 and the task says 29) |

*(The step marks in the task text - 24 + 20 + 29 - come to 73, and the task
declares 75; the rubric's own totals are 24 + 20 + 31 = 75. The rubric wins.)*

The rubric scores each row on a 0-6 scale with named descriptors (for
example, "Survey/Questionnaire": 6 = proof of 40 e-mails, 5 = 30, 4 = 20, 3 =
10, 2 = 5, 1 = fewer than 5).

## 6. The PAT assessment tool (Appendix N)

170 marks, converted to 100, over two phases and four tasks.

| Phase | Task | What | Marks |
|---|---|---|---|
| **1** | 1 | Task definition and information-finding strategies | 33 |
| | 2 | Access information and determine relevance; use the information - planning | 37 |
| | | **Phase 1 total** | **70** |
| **2** | 1 | Processing and analysing - create documents: **word processing (25, compulsory for everyone)** plus the **best two** of spreadsheet (25), database (25) and a third package (25) - the third package may be a presentation, a movie/video or a website. Only the top two package marks count, out of 50 | 25 + 50 |
| | 2 | Use the information - final presentation and synthesis (the report), marked out of 35 and **converted to 25** | 25 |
| | | **Phase 2 total** | **100** |
| | | **PAT total** | **170 -> 100** |

*(The table's own arithmetic: word processing 25 is compulsory, and 50 more
come from the two best of the other packages, so a candidate is really
assessed on three packages out of a possible five.)*

**Phase 1, Task 1 (33)** - task definition (5); main question or objective
(2); **a variety of at least 15 questions of different types and categories,
correctly identified** (10, banded down to "a few (<10) of one type and
category" for 1); questions grouped in a table with relevant headings (2); a
questionnaire or survey created in Word or other software such as Google
Forms (2); **three or more types of source apart from questionnaires**, with
relevant sources for every question (6); criteria for how the information
will be accessed, gathered, recorded, evaluated and organised - search
keywords, URLs, survey questions, e-mail details, which packages will
organise the data (6).

**Phase 1, Task 2 (37)** - relevant information found for all the questions
(3); evidence of at least three different good, relevant sources - notes,
clippings, scans, photocopies, brochures, screen dumps, printouts, completed
questionnaires, interview evidence, e-mail correspondence (4); important
facts summarised, highlighted and **cross-referenced to the Phase 1 questions**
(4); evidence that the information is usable and of good quality - URL, date
created, published, updated, author (3); a numbered, complete **reference
list with citing throughout** (6); a framework showing how the information
will be organised (4); **a final plan using at least three applications - a
word-processed report plus two other packages** (6); integration between the
packages, meaningful and purposeful (2); accuracy with proof of a spellcheck
(3); time management - handed in by the due date (2).

**Phase 2, Task 2 - the report (35, converted to 25)** - title page (2);
electronically generated table of contents (2); introduction (3); outline
and heading styles (3); **body and content (10)** - logically arranged,
answering every Phase 1 question, with images, screenshots and explanations,
spreadsheet data and charts, database queries and reports, and an account of
the process followed, the obstacles met and the pros and cons of the methods
used; conclusion (3); self-evaluation and future developments (3);
bibliography and referencing (4); accuracy with proof of a spellcheck (3);
time management (2).

**Phase 2, Task 1 - the package rubrics (25 each)**

- *Word processing:* layout and formatting (3); design and use of tables, at
  least five techniques including calculations (5); columns (2); enhancements
  - WordArt, clip art, graphics, symbols, drawing, headers and footers (4);
  **advanced features** - section breaks changing orientation, comments or
  tracked changes, footnotes or endnotes, at least two hyperlinks or
  bookmarks, meaningful online forms with fields (9); integration with other
  programs - mail merge, paste special, paste link, export and import (2).
- *Spreadsheet:* design for easy interpretation; contents using advanced
  features such as data validation, pivot tables, pivot charts, macros and
  conditional formatting; basic functions (SUM, AVERAGE, MIN, MAX, COUNT,
  COUNTA, COUNTBLANK); intermediate functions (LARGE, SMALL, COUNTIF, ROUND,
  MEDIAN, MODE, SUMIF, NOW, DATE, TODAY, LEN, LEFT, RIGHT, UPPER, LOWER);
  advanced functions (nested IF, VLOOKUP, HLOOKUP, XLOOKUP, CONCATENATE, MID,
  AND, OR, SUMIFS, COUNTIFS); multiple linked sheets; at least two types of
  graph; integration with other programs.
- *Database:* at least **two tables, five fields and ten records** of
  realistic data; at least one meaningful relationship with referential
  integrity; forms for at least two tables; **at least three meaningful input
  checks** (validation rule with text, list or combo box, default value,
  input mask); at least three meaningful queries with sorting; at least two
  meaningful reports; a switchboard or main form linking the forms;
  integration with other programs.
- *Third package:* presentation, movie/video or website, with its own rubric
  on the same 25-mark pattern (design and layout first).

## 7. Appendix L - theory curriculum content

The SAGs lays this out as three columns, Grade 10 -> 11 -> 12. Each later
grade's heading repeats the same rule: **"All [topic] concepts and skills
from Grade 10 [and Grade 11], together with the new concepts and skills, can
be assessed in Grade 11 [12]."** So the Grade 12 paper is cumulative by
design. Every topic ends with the same open row at all three grades - **"New
related technology: purpose; how do they work?; advantages and
disadvantages"** - and Social Implications ends with "Impact of new related
technologies".

### 7.1 System Technologies

**Grade 10**
- The main components of a computer system: hardware and software; definition and description of hardware
- Generic model/definition of a computer - the **Input Processing Output model (IPO)**
- Data and information: the difference; examples of their use in a familiar organisation such as the school
- The information processing cycle: input, processing, output, storage and communication
- **Introduce algorithms using pseudocode or simple English for a variety of real-life examples** (look at the simple input, processing and output for each)
- Computer types and their software: laptops, desktop, server, embedded computers, smart wear, tablets, smartphones, 2-in-1 devices, single-board computers (Raspberry Pi, Arduino); dedicated devices such as ATMs and electronic appliances; understand computers and their uses; advantages and disadvantages of using computers
- Types of input: data (unprocessed text, numbers, images, video, audio) and instructions (programs, commands, user response)
- Input devices: keyboard and mouse with **ergonomic considerations**; pointing devices (touch pad, trackball, keyboards, touch screen, stylus, joystick); digital camera; scanning and reading devices (flatbed, handheld and sheet-feed scanners, mouse scanner; RFID, magnetic stripe, bar-coding, QR code; OCR); video input (video camera, webcam); audio input (microphone, voice recognition); biometric input (fingerprint, retinal scanners)
- Types of output (text, graphics, audio, video); hard copy vs soft copy; monitors (size, quality, HDMI, VGA, FHD); printers (inkjet, laser, 3D - purpose, advantages, disadvantages, print speed, quality, cost); audio output (headsets, speakers); multifunction devices, data/DLP projector
- Storage devices and media: mechanical HDD (fixed and portable), SSD, USB flash drives, optical drives (CD, DVD, Blu-Ray), memory cards and card reader; **capacity in KB, MB, GB, TB, PB, EB**; robustness and capacity; **primary storage (memory) vs secondary storage**
- System unit: motherboard, CPU, primary storage memory (BIOS, RAM, ROM), secondary storage, peripherals; measuring speed in GHz
- Identify hardware components; ports and connectors (network, USB and its variations, HDMI/VGA); methods for connecting peripherals (cabled, wireless - USB, Bluetooth, Wi-Fi)
- **Define and describe convergence**
- Software components: definition; system vs application software; GUIs - icons, toolbars, menus and navigation, radio buttons, checkboxes, dialogs, lists, combo boxes; minimising, restoring, resizing, moving and closing windows; freeware, shareware and proprietary software; open source (definition, benefits, disadvantages); licensing agreements - end-user, site licence, **subscription model**, Creative Commons
- System software: define and describe; the operating system's basic function and purpose; desktop, mobile and embedded operating systems; define a driver; auto configuration of devices; hot-swappable/plug-and-play; basic security (log on, username, password, screen-lock pattern, biometric scanning apps)
- Define and describe utility programs
- Application software: define and describe; Office suites, financial applications, designing, gaming/entertainment
- Windows: basic accessories (calculator, paint, snipping tool); icons, shortcuts, Start button, task bar, pinning; Start menu, notification area, search box; My Computer, My Documents, Recycle Bin; universal apps and the app stores; File Explorer; desktop background; accessing apps; creating shortcuts; adding a new peripheral
- File organisation: drives, folders and files; file types and extensions (archived/compressed, text forms, web pages; word processor, spreadsheet, database, presentation; graphics, movie, sound, animation; PDF); file specification (drive, path, filename, extension); creating, naming, renaming, opening, copying, moving, deleting and restoring; selecting one or many; searching and sorting; File Explorer hierarchy

**Grade 11**
- **Advanced information processing**: input, output, processing, storage and communication, **using algorithms to create a step-by-step solution to a real-life problem - this can include if statements and repeated code**
- The role and use of data, information, knowledge and conclusion/decision as part of information management
- Types of computers and typical features: personal, SOHO, mobile, power, **disabled users**; categorise by portable/non-portable, processing power and usage
- Input and output devices for physically challenged users; **interpret input and output device specifications given in adverts**
- Advantages, disadvantages and limitations of: scanners and digital cameras; biometric input; hand-held input devices; display devices
- Online/cloud storage (advantages and disadvantages); suitable storage media for backup; interpret storage specifications in adverts
- The role of the system unit's basic components: motherboard (houses components); CPU (processing); **RAM - and types of RAM: DRAM, SRAM, SDRAM, DDR RAM chips**; **ROM - PROM, EPROM, EEPROM**; graphics/video cards; interpret system specifications in adverts
- What other software or equipment is required (device drivers, OCR)
- Overview and basic concepts of the **start-up process (booting)**
- Basic hardware troubleshooting: disk errors; resolution; non-responding programs, mouse, keyboard; printing problems; checking used or free space; connections
- Software: basic system requirements - hard disk space, CPU, RAM; what they mean and how they link to software; software installation from portable medium or Internet download
- System software general troubleshooting: disk clean-up, wizards
- Utility programs: schedule/update, backup/archive, firewalls
- Application software installation: compatibility issues; versions, patches and service packs; updating; software for physically challenged users (screen readers, voice recognition)
- Windows: Task View, Notification Area, Action Center Quick Actions, printing (changing the default printer, printer queue management)
- File operations: sharing files; e-mailing or messaging files; advanced printing options; sharing with other users or networks; cloud storage and sharing
- File management: verifying or modifying properties and attributes (type, size, hidden, read-only); **file password protection**; import and export; compressing and decompressing

**Grade 12**
- **Analyse real-life examples using IPO and algorithms**; advanced examples of input, output, processing, storage and communication; know how to apply digital tools to communicate, gather, analyse, use information and **solve problems including using algorithms**

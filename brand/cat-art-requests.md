# CAT art: drawings the CAT Theory lessons need

Made 6 October 2026 from CAT Theory Grade 10 (`content/cattheory10/`).
Style: [cat-art-style.md](cat-art-style.md). **How it works:** a CAT lesson
names the IT drawing (`Doodle ('ram-fridge', ...)`); once `cat-ram-fridge.svg`
exists in `public/assets/doodles/`, every CAT lesson shows it instead
(`DesignArtSvg()`, lib/design.php). So a redraw needs no lesson edit - only
check that its caption still fits the new picture.

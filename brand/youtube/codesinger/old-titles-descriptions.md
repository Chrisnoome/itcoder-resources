## Qgjfqf635oM (the sample code is kept in the new description)

```
How to do output in a text-based (console / simple) Pascal program (Delphi & Lazarus).
Sample code below 
----------------------------------------------------------------------------------------------------------
Program outputDemoForVideo ;
uses crt, windows; // remove , windows if using Delphi

Begin
  // a program to demostrate output
  // first write
  write ('hello');
  write ('there');
  Write ('write leaves the output cursor at the spot after the last output');

  // now writeln
  writeln;
  writeln ('hello');
  writeln ('there');
  WriteLn ('writeln moves to the next line down after output');

  // now sound
  beep (400, 1000);

  // now colour
  TextColor(yellow);
  TextBackground(blue);
  writeln ('yellow text on a blue background');

  // now clear whole screen
  // this deletes all previous output but makes the whole screen blue
  // you also get
  // ClrEOL; (fills the whole current line with the current background)
  // think about what delLine and insLine might do - try them to find out!

  ReadLn;
  clrscr;
  // redisplay text
  WriteLn ('yellow text on a blue background');

  // now nove around on screen
  GotoXY(10, 10);
  Write ('This text starts at column 10 line 10');
  GotoXY (5, 20);
  write ('This text is at column 5, line 20');
  GotoXY(40, 3);
  TextColor(white);
  write ('white column 3 line 40');

  // when you need to find out where the cursor is use WhereX and WhereY

  // FINALLY end out program nicely...

  // readln to wait for user to press enter to stop program
  // or program will just flash on the screen and close
  // before the user can see it!
  Write ('Press enter to quit.');
  readln;

End .
```

## catdb-01.1 Your first look at Access (about 8 min)

**Goes:** after the study block (the comment sits there).
**The pupil can afterwards:** say what a database is for and when it beats a
spreadsheet; name the four objects and what each does; find the ribbon's tabs,
the Navigation Pane, an object's tab and the record navigation bar; open and
close objects; recognise the security warning and when to Enable Content; say
how Access saves; make a backup; Compact and Repair; use Tell me and F1.
**Thumbnail:** tag `CAT · DATABASES`, title "Your first look at *Access*"

### Scenes

1. **Hook (0:00-0:50).** Hi, and welcome to BestLessons. Ms Naidoo's library
   lives in a shoebox of cards. "Which Fiction books do we have?" takes an
   afternoon. A database answers it in a second - and again next term.
   > Board: a shoebox overflowing with cards; Clicky pulls one out, sighs.
2. **What a database is for (0:50-2:00).** Records and fields (a row, a
   column). Where databases are: school, shop till, clinic, bank, Home Affairs.
   Spreadsheet or database: calculate and chart vs many records for years,
   many users, checked data, the same questions again.
   > Board: two columns, "spreadsheet" and "database", ticks appearing.
3. **The four objects (2:00-3:30).** Table stores, query asks, form is for
   typing in, report prints. The tbl/qry/frm/rpt names.
   > Screen: the library database, the Navigation Pane; highlighter on each heading.
4. **The window (3:30-4:45).** Ribbon tabs (Home, Create, External Data,
   Database Tools), the Navigation Pane and its Search box and <, an object's
   tab and X, Datasheet View, the record navigation bar, the status bar.
   > Screen: double-click tblBooks; point at each part. Double-click qryFiction (the answer), close it; frmBooks, next record; rptFiction in Print Preview.
5. **Opening safely (4:45-5:45).** The yellow SECURITY WARNING bar; Enable
   Content only for files you trust - your teacher's, an exam's, these
   lessons', your own; never a stranger's attachment.
   > Screen: open the library again: the bar; Enable Content. Board: Clicky with a shield.
6. **How Access saves (5:45-7:15).** A record saves when you leave it; the
   pencil; Esc; Shift+Enter; Ctrl+S is for designs. Keep a copy: File > Save
   As > Back Up Database. Database Tools > Compact and Repair.
   > Screen: change Coconut's copies, the pencil, Shift+Enter; File > Save As; Database Tools > Compact and Repair.
7. **Help (7:15-7:45).** Tell me what you want to do; F1; tooltips.
   > Screen: type "input mask" in Tell me.
8. **Sign-off.**

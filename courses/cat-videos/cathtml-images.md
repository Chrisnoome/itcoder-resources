# Web Design (HTML) lesson 8: Pictures - video

Lesson: `AIPascalCourse/content/cathtml/images.php`. Screen recording in the
**CAT VM `itcoder-cat`** (Notepad++ and Edge). Board scenes in the CAT marker
style with Clicky; yellow highlighter on words being talked about.

## cathtml-08.1 Pictures on a web page (about 8 min)

**Goes:** the comment `// VIDEO cathtml-08.1`, after the order question in `#broken`.
**The pupil can afterwards:** add a picture from the site's folder or an img folder, give it alt text, size it, frame it, place it, and find out why a picture will not show.
**Thumbnail:** tag `CAT · HTML`, title "Why won't my *picture* show?"

### Scenes

1. **Hook (0:00-0:40).** Hi, and welcome to BestLessons. Nobody buys a koeksister because of a paragraph. Mr Botha wants pictures.
   > Board: Clicky carrying a photo frame towards a web page.
2. **The folder (0:40-1:40).** The website is a folder; copy pictures into it or its img folder; switch on File name extensions; short lower-case names.
   > Screen: File Explorer in the VM: View > Show > File name extensions; the botha folder and its img folder (G:\My Drive\CAT\HTML\botha).
3. **img and src (1:40-3:00).** No closing tag; src with the exact name; img/cake.png with a forward slash; never a C:\ path.
   > Screen: type the img tag in Notepad++, save, refresh in Edge.
4. **alt (3:00-4:30).** For screen readers, for when the picture cannot load, for search engines; what good alt text says.
   > Board: Gogo's friend listening to a screen reader; highlighter on the alt text.
5. **Size, border, align (4:30-6:30).** Width or height (keep the proportion), border, align left/right for text flow, a centred paragraph to centre. IEB: title for a tooltip.
   > Screen: width 300, then a squashed 600 by 200; align right with the paragraph flowing.
6. **Broken pictures (6:30-7:40).** Name, extension, folder, attribute, capitals.
   > Screen: src koeksisters.jpg - Edge's broken-picture icon and alt text (as cathtml-images-2.png); fix it.
7. **Sign-off.**

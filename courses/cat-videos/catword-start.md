# catword lesson 1: The Word window and your first document - videos

Lesson: `content/catword/start.php` (Grade 10). Screen recordings in the
**CAT VM `itcoder-cat`** (Word 365, Google Drive signed in), window at
1750 x 720 like the lesson's pictures. **Never show the title bar's account
or Backstage's middle column** (it names the school's OneDrive account):
crop or blur it, or record the Save As page with Recent selected and the
camera on the right-hand column. Board scenes in the CAT marker style with
Clicky; yellow highlighter on the words being talked about.

## catword-01.1 The Word window and typing your first document (about 8 min)

**Goes:** after the Explore picture in section `#window` (the comment
`// VIDEO catword-01.1`).
**The pupil can afterwards:** start Word, open a blank document, name the
parts of the window (File tab, ribbon, tabs, groups, dialog box launcher,
page, insertion point, status bar, views, zoom), and type with word wrap.
**Thumbnail:** tag `CAT · WORD`, title "Your *first* Word document"

### Scenes

1. **Hook (0:00-0:40).** Hi, and welcome to BestLessons. Mr Botha's bakery
   closes on 16 December and he needs a notice for the door. Thabo offers to
   type it - on a computer, for the first time.
   > Board: the bakery door, Clicky holding a blank page.
2. **Starting Word (0:40-1:40).** Start button, type Word, click Word. The
   Home page: Blank document and the templates (CV, minutes). More templates.
   Ctrl+N.
   > Screen: Start > Word > Home page; point at Blank document, then hover over two templates; click Blank document.
3. **The window (1:40-4:00).** Title bar with the Quick Access Toolbar and
   AutoSave (name them, do not show the account). File tab. The ribbon:
   tabs, groups, buttons - Home tab > Font group > Bold. ScreenTips (rest the
   mouse on Bold). The small arrows. The dialog box launcher of the Font
   group opens the Font dialog box - Cancel. Extra tabs appear (click in a
   table to show Table Design - then undo). The page, the insertion point,
   the status bar (page, word count), the views and the zoom slider (zoom in
   and out: the printed size does not change). Ctrl+F1 hides the ribbon.
   > Screen: each part in turn with a yellow highlighter box; the View tab > Ruler.
   > Board: the ribbon as a kitchen - cupboards (tabs), shelves (groups), cups (buttons).
4. **Typing (4:00-6:30).** Click on the page and type Botha's Bakery, Enter.
   Type the long paragraph without Enter: watch word wrap. Enter only at
   the end of a paragraph. One space after a full stop or comma, none before.
   Shift for a capital, Caps Lock for many. Backspace and Delete.
   > Screen: type the notice; at the end of a line keep typing - highlight the word that jumps down.
   > Board: the typewriter-way (Enter at every line) - then the font made bigger and the lines broken; Clicky groans.
5. **Pages, paragraphs, lines, objects (6:30-7:30).** Turn on Show/Hide for
   a moment: each ¶ ends a paragraph. A picture is an object among them.
   > Screen: Show/Hide on and off.
6. **Sign-off.**

## catword-01.2 Saving your work in the cloud, with a good name (about 6 min)

**Goes:** after the prose of section `#cloud` (the comment `// VIDEO catword-01.2`).
**The pupil can afterwards:** save a new document into a CAT folder on
Google Drive or OneDrive with a good name, save changes with Ctrl+S, know
when to use Save As, close and open a document, and find Version History.
**Thumbnail:** tag `CAT · WORD`, title "Save it in the *cloud*"

### Scenes

1. **Hook (0:00-0:40).** The power goes off before Thabo saves. The notice
   is gone - it was only in memory.
   > Board: a laptop screen going dark, Clicky with an empty page.
2. **Why the cloud (0:40-1:50).** OneDrive (Microsoft 365, school account)
   and Google Drive (drive G:, My Drive). There at school, home and on the
   phone; safe if the laptop breaks; share with a link; earlier versions
   kept. One CAT folder with a folder per program: My Drive > CAT > Word.
   > Board: one file in a cloud, arrows to a laptop, a phone and a school PC.
3. **Save As (1:50-3:30).** File > Save As > Recent: the Word folder in
   G: > My Drive > CAT. Type Botha notice 2026-12-16, Save. Word adds .docx.
   Then Browse for any other folder.
   > Screen: the right-hand column of the Save As page only.
4. **Good names (3:30-4:30).** Say what it is; dates year-month-day; v1, v2,
   never "final"; the nine forbidden characters.
   > Board: Document1, Document2, final FINAL - each crossed out; Botha notice 2026-12-16 ticked.
5. **Ctrl+S, Save As, AutoSave (4:30-5:20).** Change 07:00 to 06:30, Ctrl+S.
   Save As (F12) only for a copy. AutoSave for OneDrive files.
6. **Close, open, Info (5:20-6:00).** Ctrl+W (Save / Don't Save / Cancel).
   Home page recent list with the folder under each name; Open, Ctrl+O.
   File > Info: Protect Document, Inspect Document, Version History.
7. **Sign-off.**

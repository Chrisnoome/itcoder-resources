# catword lesson 25: Linking and embedding - videos

Lesson: `content/catword/linking.php` (Grade 12). Screen recordings in the
CAT VM (Word 365 and Excel 365), starting from Botha report.docx and Botha
sales.xlsx in the same folder (G:\My Drive\CAT\Word). Never show the title
bar's account. Board scenes in the CAT marker style with Clicky; yellow
highlighter on what is talked about. Both boards. Never "in the exam".

## catword-25.1 Paste, embed or link (about 8 min)

**Goes:** after the written question `wLinkDisadv`, before section
`#objects` (the comment `// VIDEO catword-25.1`).
**The pupil can afterwards:** tell a pasted, an embedded and a linked table
apart, paste a link with Paste Special, insert a file as an object (linked,
as an icon), update a link, and use the Links box (Change Source, Break
Link) - and choose the right way for a job.
**Thumbnail:** tag `CAT · WORD`, title "Copy, parcel or *phone line*?"

### Scenes

1. **Hook (0:00-0:40).** Hi, and welcome to BestLessons. The bookkeeper
   fixed March in Excel - and the bank manager got the old total.
   > Board: a Word page with an old number and an Excel sheet with a new
   > one, a gap between them; Clicky with a broken string.
2. **Three ways in (0:40-2:00).** Paste is a copy; embed is a parcel inside
   the document; link is a phone line to the workbook. Source and
   destination. OLE.
   > Board: the three side by side - a photocopy, a parcel, a telephone;
   > yellow highlighter on "updates".
3. **Paste link, which form (2:00-3:40).** Grade 11 linked with Paste Special - a quick recap, then the forms: Excel object, Formatted Text (RTF), Picture. Copy A1:E6 in Excel; in Word Home > Paste
   arrow > Paste Special (Ctrl+Alt+V) > Paste link > Formatted Text (RTF) >
   OK. Change D2 to 5200 in Excel, save; right-click the table > Update
   Link: the totals change.
   > Screen: each click; the number changing.
4. **Embed (3:40-4:40).** Paste Special > Paste > Microsoft Excel Worksheet
   Object: double-click - Excel's ribbon inside Word. Change Excel: nothing
   happens here.
5. **Insert > Object (4:40-5:50).** Insert > Object > Create from File >
   Browse > Link to file > Display as icon > OK; double-click the icon.
6. **The Links box (5:50-7:00).** File > Info > Edit Links to Files: Update
   Now, Open Source, Change Source (the workbook was moved), Break Link
   (before sending). Format at the source.
7. **Which way? (7:00-7:40).** Will the numbers change? Link. Must it travel
   alone and stay editable? Embed. Neither? Paste.
8. **Sign-off.**

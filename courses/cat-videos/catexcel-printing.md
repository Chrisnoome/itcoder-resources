# CAT Spreadsheets lesson 8: Printing, sharing and solving problems - videos

Lesson: `AIPascalCourse/content/catexcel/printing.php` (Grade 10). Written to
[../cat-practical-writing.md](../cat-practical-writing.md), 8 October 2026.
Screen recordings in the **CAT VM `itcoder-cat`** (Excel 365 and Word 365)
on the lesson's workbook - Ms Naidoo's Grade 10A marks (sheet Marks, 40
pupils) and Mr Botha's order (sheet Orders); `tools/sim-screens/

## catexcel-08.1 A sheet onto paper (about 7 min)

**Goes:** after the prose block "Look before you print" (section
`#preview`).
**The pupil can afterwards:** check the pages in Print Preview; set the
orientation, size and margins; (IEB) repeat the headings on every page,
set a print area and see the pages in Page Break Preview; (CAPS) add a
header and footer with page numbers; print copies.
**Thumbnail:** tag `CAT · SPREADSHEETS`, title "Why did it print on *4 pages*?"

### Scenes

1. **Hook (0:00-0:40).** Hi, and welcome to BestLessons. Ms Naidoo clicked
   Print and got four pages - two columns alone on a page, and no headings
   after page 1. A sheet is not a page.
   > Board: Clicky holding up four pages, the last one with one lonely column.
2. **Print Preview (0:40-1:40).** File > Print (Ctrl+P): the settings on the
   left, every page on the right. Go through the pages; Esc to go back.
   > Screen: the Print page; highlighter on "1 of 4".
3. **Landscape (1:40-2:30).** Page Layout > Orientation > Landscape; Size A4;
   Margins. The dashed lines.
   > Screen: the menu; highlighter on the dashed page breaks.
4. **Print Titles (2:30-3:40)** (IEB; CAPS in Grade 11). Page Layout > Print
   Titles > Rows to repeat at top: $1:$1 > OK. Print Preview: page 2 has
   headings.
5. **Print Area, breaks and the views (3:40-4:50)** (IEB). Set Print Area;
   Breaks > Insert Page Break; View > Page Break Preview, drag a blue line;
   Page Layout view.
6. **Header and footer (4:50-5:50)** (CAPS). Insert > Header & Footer; type
   the title; Page Number and Number of Pages in the footer.
7. **Printing (5:50-6:30).** Copies 2, the printer (or Microsoft Print to
   PDF), pages - and stop before Print.
8. **Sign-off.**

## catexcel-08.2 Wrong answers with no error (about 5 min)

**Goes:** after the prose block "Solving common problems" (section
`#problems`), before the simulation `simShowFormulas`.
**The pupil can afterwards:** find a typed answer, a number stored as text,
a formula without = and a short range, with Show Formulas, and fix each.
**Thumbnail:** tag `CAT · SPREADSHEETS`, title "The total is *wrong* - and no error"

### Scenes

1. **Hook (0:00-0:30).** Hi, and welcome to BestLessons. Mr Botha's order
   sheet looks finished. Every total is wrong.
   > Screen: the Orders sheet; Board: Clicky with a magnifying glass.
2. **Show Formulas (0:30-1:20).** Formulas > Show Formulas (Ctrl+`): D4 is
   240, typed. Type =B4*C4.
3. **Text that looks like a number (1:20-2:30).** C5: left-aligned, green
   triangle - '36. SUM skips it: 89 instead of 125. Retype 36, or Convert to
   Number.
4. **No = (2:30-3:10).** D6 shows B6*C6. Type =B6*C6.
5. **A short range (3:10-4:10).** D7 is =SUM(D4:D6); fix it to =SUM(D2:D6).
6. **Into Word (4:10-4:50).** Select A1:D7, Ctrl+C; in Word, Ctrl+V - a Word
   table of values; the Paste Options button.
   > Screen: Word with the letter; highlighter on the Paste Options button.
7. **Sign-off.**

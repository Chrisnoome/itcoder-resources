## cathtml-10.1 Tables: rows, cells and headings (about 7 min)

**Goes:** the comment `// VIDEO cathtml-10.1`, after the typed question in `#th` (inside the CAPS section).
**The pupil can afterwards:** plan a table on paper, build it row by row with table, tr, td and th, and fix a broken table.
**Thumbnail:** tag `CAT · HTML`, title "Tables, *row by row*"

### Scenes

1. **Hook (0:00-0:40).** Hi, and welcome to BestLessons. Mr Botha's opening hours are a paragraph nobody can read. They belong in a table.
   > Board: the hours paragraph, then a grid drawn over it.
2. **Plan on paper (0:40-1:40).** Rows across, columns down; count rows and columns; every row the same number of cells.
   > Board: the 4 by 3 grid with the counts.
3. **table, tr, td (1:40-3:40).** Row by row; no column tag; indenting; border="1" to see it (more in Grade 12).
   > Screen: build the hours table in Notepad++, refresh after each row.
4. **th (3:40-5:00).** Header cells, bold and centred; screen readers use them.
   > Screen: change the top row's td to th.
5. **Mistakes (5:00-6:40).** Missing table tag, a cell outside a row, a short row, th closed with /td, words outside any cell.
   > Screen: the fix-it file repaired.
6. **Sign-off.**

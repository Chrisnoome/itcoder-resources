## cathtml-15.1 Building a page for a scenario (about 8 min)

**Goes:** the comment `// VIDEO cathtml-15.1`, after the written question in `#example`.
**The pupil can afterwards:** read a scenario task like a checklist, build the page top to bottom, and match a page to an example picture.
**Thumbnail:** tag `CAT · HTML`, title "From *task* to web page"

### Scenes

1. **Hook (0:00-0:40).** Hi, and welcome to BestLessons. Ms Naidoo hands Thabo a folder: a half-built page, a picture, and a numbered list.
   > Board: a folder opening, Clicky reading a numbered list.
2. **Read like a checklist (0:40-2:30).** Read every part; underline exact words; circle every setting; write the tag next to each; find the files; every part is marked on its own.
   > Board: the farewell task list with underlines and circles in highlighter.
3. **Build in order (2:30-5:00).** Head, body tag, top of the page, each part; save, refresh, look; type both tags of a pair first.
   > Screen: the farewell page (farewell.html) built part by part in Notepad++ and Edge.
4. **Resemble the example (5:00-7:00).** Compare headings, text, lines, lists, pictures, tables with the picture, piece by piece.
   > Screen: an example picture beside the page; differences circled and fixed.
5. **The last check (7:00-7:40).** Comments kept, every tag closed and nested.
   > Board: the checklist ticked.
6. **Sign-off.**

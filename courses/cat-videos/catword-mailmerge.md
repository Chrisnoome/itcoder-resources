# catword lesson 17: Mail merge: letters - videos

Lesson: `content/catword/mailmerge.php` (Grade 11). Screen recordings in the
CAT VM (Word 365 and Excel), starting from Parents evening letter.docx and
Grade 11 parents.xlsx (G:\My Drive\CAT\Word). Never show the title bar's
account; paint out the Add-ins group; the parents' e-mail addresses are
example.co.za addresses. Board scenes in the CAT marker style with Clicky;
yellow highlighter on what is talked about.

## catword-17.1 The main document and the data source (about 8 min)

**Goes:** after the quiz `q17Filter`, before section `#fields` (the comment
`// VIDEO catword-17.1`).
**The pupil can afterwards:** name the three parts of a mail merge, start a
merge of letters, join a spreadsheet as the data source, and choose, sort
and filter the recipients.
**Thumbnail:** tag `CAT · WORD`, title "One letter, *64* parents"

### Scenes

1. **Hook (0:00-0:40).** Hi, and welcome to BestLessons. "Dear Parent" goes
   in the bin; "Dear Mrs Khumalo... Sipho's teachers" gets read. 64 letters
   without typing 64.
   > Board: one letter going into a machine, 64 envelopes coming out, each
   > with a different name; Clicky turning the handle.
2. **Three parts (0:40-2:00).** Main document, data source (a row per
   person, headings in row 1), merge fields. The Mailings tab, left to right.
   > Screen: Grade 11 parents.xlsx in Excel - the headings row highlighted.
3. **Start and recipients (2:00-5:00).** Mailings > Start Mail Merge >
   Letters. Select Recipients > Use an Existing List... > Grade 11
   parents.xlsx > Select Table: Parents$, first row has headers > OK.
4. **Edit Recipient List (5:00-7:00).** Untick a parent; sort by LastName;
   Filter...: Class Equal to 11A. Change people in the spreadsheet, not in
   Word.
5. **Sign-off.**

## catword-17.2 Merge fields, preview and finish (about 7 min)

**Goes:** after the written question `w17Why`, before the scenario (the
comment `// VIDEO catword-17.2`).
**The pupil can afterwards:** insert merge fields, Address Block and
Greeting Line, preview and check the letters, and finish the merge.
**Thumbnail:** tag `CAT · WORD`, title "From *«LastName»* to Khumalo"

### Scenes

1. **Fields (0:00-2:30).** Replace each [placeholder]: select it, Insert Merge
   Field > the field. Type the spaces between fields. Address Block and
   Greeting Line; Highlight Merge Fields; Match Fields. Never type « ».
   > Screen: the letter, Dear «Title» «LastName».
2. **Preview (2:30-4:00).** Preview Results; the record arrows; Find
   Recipient. Spot "Dear MrsKhumalo" and fix the space.
   > Board: Clicky with a magnifying glass over "MrsKhumalo".
3. **Finish (4:00-6:00).** Finish & Merge > Edit Individual Documents... >
   All > OK: Letters1, a letter per section - check and save. Print
   Documents; Send Email Messages (lesson 18). Save the main document too;
   say Yes to the SQL question next time.
4. **Sign-off.**

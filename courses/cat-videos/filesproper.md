# CAT 11 lesson 9: Managing files properly - videos

Lesson: `content/cattheory11/filesproper.php`. Three videos: setting up and
grouping a folder, searching by property and importing a CSV file, and (IEB)
the Details tab and passwords. Board in the CAT marker style with Clicky
(brand/cat-art-style.md); yellow highlighter on any words on screen being
talked about. Everything below is in the lesson text.

**Screens:** all three need real screens, recorded in the video VM (Windows
11 File Explorer, Excel, Word). Before recording, make a folder `Bakery stuff`
with about 40 mixed files - Word documents named `Doc1.docx` to `Doc14.docx`
(some dated last month), a few `.xlsx`, photos `IMG_2041.jpg` to `IMG_2080.jpg`
(one of a cake), and `prices.csv` with the four lines in the lesson. Turn on
file name extensions first.

## cat11-09.1 Setting up, sorting and grouping a folder (about 6 min)

**Goes:** after section `#group` - the comment after `w9SortGroup`.
**The pupil can afterwards:** switch on the preview and details panes, group a folder by a property, sort inside the groups, and say how sorting differs from grouping.
**Thumbnail:** tag `CAT · FILES`, title "Sort it or *group* it?"

### Scenes

1. **Hook (0:00-0:40).** Hi, and welcome to BestLessons. Mr Botha's folder Bakery stuff holds 600 files - invoices, recipes, cake photos, all mixed up. Lerato has a morning to sort it out.
   > Board: an overflowing folder, Clicky buried under paper.
2. **A quick recap (0:40-1:20).** Details view, file name extensions, hidden items, adding a column - all from Grade 10.
   > Screen: View > Details; View > Show > File name extensions; right-click a column heading > Date created.
3. **The panes (1:20-2:50).** A pane is one part of a window. The preview pane (Alt + P) shows what is inside a file without opening it; the details pane (Alt + Shift + P) shows its properties. They share the right-hand side. Worked example: find the wedding cake among 40 IMG photos with the preview pane and the down arrow.
   > Screen: View > Show > Preview pane; click IMG_2041.jpg; press the down arrow until the cake shows. Then Alt + Shift + P to switch to the details pane. Yellow highlighter on "Preview pane".
4. **Group by (2:50-4:30).** Grouping splits the list into groups under headings. Sort > Group by > Type: headings for each type, with a count. Collapse a group with its arrow. Group by Date modified (Today, Last month...) and Size (Small, Medium, Large). Switch off: Group by > (None). Right-click an empty part of the list works too.
   > Screen: Sort > Group by > Type; collapse JPG File; Sort > Group by > Date modified; then (None).
5. **Sorting against grouping (4:30-5:30).** Sorting lines everything up in one list; grouping puts like with like under headings - the socks in one basket, the shirts in another. Sorting still works inside each group: group by Type, then click Size until the biggest is at the top of each group. Neither moves a file.
   > Board: laundry - socks in a row (sorted) against three baskets (grouped). Yellow highlighter on "nothing is moved".
6. **Sign-off.**

## cat11-09.2 Searching well, and importing a CSV file (about 8 min)

**Goes:** after section `#import` - the comment after `t9Delimiter`.
**The pupil can afterwards:** search by date, kind and size with Search options or a typed filter, and import a CSV file into Excel; say what importing, exporting and a delimiter are, and what a CSV file loses.
**Thumbnail:** tag `CAT · FILES`, title "Find it *without* its name"

### Scenes

1. **Hook (0:00-0:30).** Hi, and welcome to BestLessons. Mr Botha needs last month's invoices - but they are called Doc14.docx and the like. Searching by name will not help.
   > Board: a row of files all called "Doc", Clicky scratching its head.
2. **Search options (0:30-2:00).** A search filter keeps only the files with a property. Click in the search box; Search options; Date modified > Last month. Also Kind and Size.
   > Screen: open Bakery stuff, click the search box, Search options > Date modified > Last month; then Kind > Picture; then Size. Yellow highlighter on the filter as it appears in the box.
3. **Typing a filter (2:00-3:10).** Property, colon, value - no space after the colon: `datemodified:last month`, `kind:picture`, `size:>5MB`. A word and a filter together keep only files that match both: `invoice datemodified:last month`. File contents: Search options > Advanced options > File contents, for places like a flash drive - slower.
   > Screen: type each filter in turn; show Advanced options > File contents.
4. **Importing and exporting (3:10-4:20).** Importing brings data in from another format; exporting saves a copy out for another program. Why not retype 300 prices? Hours of work, and every typing mistake is a wrong price. The go-between formats: CSV, TXT, RTF - and PDF for reading, not for data.
   > Board: an arrow into Excel labelled IMPORT, an arrow out labelled EXPORT; the four formats on sticky notes.
5. **Inside a CSV file (4:20-5:10).** prices.csv opened in Notepad: headings on line 1, one record per line, a comma between the values. The comma is the delimiter.
   > Screen: open prices.csv in Notepad. Yellow highlighter on each comma.
6. **Importing into Excel (5:10-6:40).** Click the start cell; Data > From Text/CSV; choose prices.csv; Import; check the Delimiter is Comma - all in one column means it is wrong; Load.
   > Screen: the five steps in Excel, one at a time.
7. **Exporting, and what CSV loses (6:40-7:40).** File > Save As > CSV (Comma delimited). Excel warns: a CSV file keeps only the values on this sheet - no formatting, no formulas (only their answers), no charts, no other sheets. Keep the .xlsx too. (Access imports with External Data > New Data Source > From File > Text File; Word takes text with Insert > Object > Text from File - shown in the lesson.)
   > Screen: Save As CSV and the warning bar. Yellow highlighter on the warning.
8. **Sign-off.**

## cat11-09.3 File details and passwords (IEB, about 5 min)

**Goes:** after the IEB section `#details` / `#passwords` - the comment after the board section.
**The pupil can afterwards:** find a file's metadata on the Details tab, say what the Description, Origin, Image and Media headings hold, change the Authors, remove GPS details before sharing, and password-protect an Office file.
**Thumbnail:** tag `CAT · FILES · IEB`, title "What your photo *knows*"

### Scenes

1. **Hook (0:00-0:30).** Hi, and welcome to BestLessons. Thabo posts a photo of his new bike, taken in his front yard. The photo knows exactly where his yard is.
   > Board: a photo with a map pin hidden in its corner; Clicky with a magnifying glass.
2. **The Details tab (0:30-2:00).** Right-click > Properties > Details: the file's metadata - data about data. Description (title, tags), Origin (authors, date taken), Image (dimensions), GPS (latitude, longitude), Media (artist, album, length). Like what is written on an envelope.
   > Screen: Properties > Details for a photo, then a song, then a Word document. Yellow highlighter on each heading.
3. **Changing a property (2:00-2:50).** Ms Naidoo wants the exam number as the Author: Details tab, click next to Authors, type, OK. Length and Dimensions cannot be changed. Also under File > Info in Office.
   > Screen: the five steps on a spreadsheet.
4. **Metadata and privacy (2:50-3:40).** Remove Properties and Personal Information > Create a copy with all possible properties removed. Or switch off location for the camera.
   > Screen: the Remove Properties dialog.
5. **A password (3:40-4:50).** Read-only and hidden don't keep a file private; a password does - the file is encrypted. File > Info > Protect Document (Protect Workbook in Excel) > Encrypt with Password; type it twice; save. Forget it and the file is lost. Windows' ZIP cannot add a password.
   > Screen: Encrypt with Password in Word, then reopen the file to show the prompt.
   > Board: the read-only / hidden / password table, a row at a time.
6. **Sign-off.**

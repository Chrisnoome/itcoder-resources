# Web Design (HTML) lesson 9: Links - video

Lesson: `AIPascalCourse/content/cathtml/links.php`. Screen recording in the
**CAT VM `itcoder-cat`** (Notepad++ and Edge). Board scenes in the CAT marker
style with Clicky; yellow highlighter on words being talked about.

## cathtml-09.1 Links to pages, websites and files (about 8 min)

**Goes:** the comment `// VIDEO cathtml-09.1`, after the picture-link quiz in `#picture`.
**The pupil can afterwards:** link to another page, a file, another website and a picture as a link, make bookmarks (id for CAPS, a name for the IEB) and find broken links.
**Thumbnail:** tag `CAT · HTML`, title "Every *link*, explained"

### Scenes

1. **Hook (0:00-0:40).** Hi, and welcome to BestLessons. Mr Botha's website has two pages and no door between them.
   > Board: two pages as rooms; Clicky drawing a door labelled a href.
2. **The a tag (0:40-2:00).** Href says where; link text says what; close it or the rest of the page becomes a link; link text that says where it goes.
   > Screen: Notepad++: Cakes to order linked to cakes.html; click it in Edge.
3. **Pages, files, websites (2:00-4:00).** A file name; a folder and a slash; https:// for another website; copy the address from the address bar.
   > Screen: link to docs/menu.pdf; link to bestlessons.co.za with and without https://.
4. **A picture as a link (4:00-5:00).** The img between <a> and </a>; alt text says where it goes; border="0".
   > Screen: the logo linked to index.html.
5. **Bookmarks (5:00-7:00).** Name the place, link with #. CAPS: id="top", and target="_blank" for a new tab. IEB: <a name="top"></a>.
   > Screen: Back to the top on the long price list; then the BestLessons link opening in a new tab.
6. **Broken links (7:00-7:40).** Href spelling, file and extension, folder, https://, the #, the closing tag.
   > Board: a checklist with ticks.
7. **Sign-off.**

# catword lesson 9: Proofing and printing - videos

Lesson: `content/catword/proofing.php` (Grade 10). Screen recordings in the
CAT VM (Word 365), starting from ThaboEssay.docx (G:\My Drive\CAT\Word).
Never show the title bar's account. Board scenes in the CAT marker style with
Clicky; yellow highlighter on what is talked about.

## catword-09.1 Spelling, grammar and the Editor (about 7 min)

**Goes:** after the quiz `q9WordCount` in section `#thesaurus` (the comment
`// VIDEO catword-09.1`).
**The pupil can afterwards:** read the wavy lines, fix a word from the
right-click menu, use Ignore All and Add to Dictionary, check a whole
document with F7, undo an AutoCorrect change, and use the thesaurus and the
word count.
**Thumbnail:** tag `CAT · WORD`, title "Check *before* you print"

### Scenes

1. **Hook (0:00-0:40).** Hi, and welcome to BestLessons. "I want to recieve
   a bursary" - on the printout the panel reads first.
   > Board: Clicky with a red pen, circling "recieve".
2. **The wavy lines (0:40-2:00).** Red: spelling (and the same word twice);
   blue double: grammar. Right-click recieve, receive. Ignore All; Add to
   Dictionary (Mokoena). The language on the status bar: English (South
   Africa).
3. **The Editor pane (2:00-3:20).** Review, Spelling & Grammar (F7); the
   repeated word; Delete Repeated Word; on to the next.
4. **What Word misses (3:20-4:00).** "Over their": a real word, used
   wrongly. Read it aloud.
   > Board: "their / there / they're" on three signposts.
5. **AutoCorrect (4:00-5:20).** teh, a small letter after a full stop,
   straight to curly quotes, word--word to a dash, (c) to the copyright
   sign; Ctrl+Z straight away. File > Options > Proofing > AutoCorrect
   Options.
6. **Thesaurus and word count (5:20-6:30).** Double-click like, Shift+F7;
   right-click > Synonyms. The status bar: "38 of 245 words"; Review > Word
   Count.
7. **Sign-off.**

## catword-09.2 Views, printing and PDF (about 7 min)

**Goes:** after the written question `w9StillRead` in section `#pdf` (the
comment `// VIDEO catword-09.2`).
**The pupil can afterwards:** add and resolve a comment, switch between the
views, zoom, work with two windows, check the print preview, set the print
settings (pages 2-4,7) and save a document as a PDF.
**Thumbnail:** tag `CAT · WORD`, title "Print it *right*"

### Scenes

1. **Comments (0:00-1:20).** Select software developer; Review, New
   Comment; Reply; Resolve; Delete.
2. **Views and zoom (1:20-3:00).** Print Layout, Read Mode (Esc), Web
   Layout, Draft; the zoom slider, Ctrl + mouse wheel, One Page, Page Width;
   View Side by Side; New Window.
3. **Print (3:00-5:00).** File, Print (Ctrl+P): the preview, Copies,
   Printer, Pages (2-4,7), sides, orientation, size, margins, pages per
   sheet; then the Print button.
   > Board: a row of pages 1 to 7 with 2-4 and 7 highlighted.
4. **PDF (5:00-6:30).** File, Save As, PDF; Export, Create PDF/XPS;
   Microsoft Print to PDF. Keep the .docx.
   > Board: one PDF opening the same on a laptop and a phone.
5. **Sign-off.**

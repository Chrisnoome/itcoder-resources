## catdb-07.1 Your first queries in Design View (about 9 min)

**Goes:** after the study block.
**The pupil can afterwards:** say what a select query does; use the Simple Query
Wizard; build a query in Query Design; write criteria for numbers, text, dates
and Yes/No; sort; hide a field with Show; run and save; (IEB) read SQL View;
fix Enter Parameter Value, no records and data type mismatch.
**Thumbnail:** tag `CAT · DATABASES`, title "Ask your database a *question*"

### Scenes

1. **Hook (0:00-0:40).** Hi, and welcome to BestLessons. Every week Ms Naidoo
   needs another tour list. Ask once, save the question, run it again.
2. **What a query does (0:40-1:30).** Which fields, which records, which order;
   a select query changes nothing; always today's data.
   > Board: the sieve, with fields as columns being picked.
3. **The Simple Query Wizard (1:30-2:20).** Fields only - no criteria.
4. **Query Design (2:20-4:00).** Create > Query Design; Add Tables; double-click
   fields; the grid's rows.
   > Screen: qryGrade11 built from empty.
5. **Criteria (4:00-6:00).** 11; >=1500; "Soweto"; <>"Soweto"; #2009/01/01#; Yes.
6. **Sort and Show (6:00-6:50).** Ascending/Descending; untick Show for Town.
7. **Run and save (6:50-7:30).** Run; count the records; Ctrl+S, qry names.
8. **IEB: SQL View (7:30-8:10).** SELECT, FROM, WHERE, ORDER BY.
9. **When it goes wrong (8:10-8:50).** Enter Parameter Value; no records; data
   type mismatch.
10. **Sign-off.**

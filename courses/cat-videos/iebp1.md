Lesson: `content/cattheory12/iebp1.php` (IEB only - the whole lesson is an
IEB board section). Two videos: the Data Files folder and Section A, and how
the memo marks. Board in the CAT marker style with Clicky
(brand/cat-art-style.md); yellow highlighter on any words on screen being
talked about. Screen recordings in the VM (Windows 11 File Explorer, Excel,

## cat12-27.1 The Data Files folder and Section A (about 8 min)

**Goes:** after section `#sectionA` - the comment after `q27Crop`.
**The pupil can afterwards:** set up the Data Files folder at the start, work by the folder rules, and answer Section A with screenshots that earn the mark.
**Thumbnail:** tag `CAT · PAPER I`, title "*Nine* folders, one rule"

### Scenes

1. **Hook (0:00-0:40).** Hi, and welcome to BestLessons. Thabo moved the pictures next to the web page so it could find them. The page worked. He lost the marks.
   > Board: the folder-tree drawing with Q1 to Q9; a picture icon being dragged out of `img`, Clicky shaking his head.
2. **The paper (0:40-1:50).** 180 marks scaled to 100, five sections, nine questions: A file management 16-20, B word processing 50, C spreadsheet 50 (Question 7 always one 5-mark feature), D database 40, E HTML 20-24. About 100 parts, more than half worth 1 mark. The appendix: tag list and input masks.
   > Board: the five sections as blocks; highlighter on "Q7 = 5".
3. **The first five minutes (1:50-3:20).** Check the paper; rename Data Files to the examination number; open each Q folder; read the scenario; start - in the question's own folder.
   > Screen: the practice Data Files folder renamed to a made-up number; Q1 to Q9 opened in turn; highlighter on Student_Screenshots.docx.
4. **Why the folders matter (3:20-4:30).** The marker opens Q6 for Question 6. Files point at each other by name and place - the web page's `img/logo.png`. An extra copy leaves the marker guessing.
   > Board: a web page with an arrow into `img/logo.png`; the arrow snaps when the picture moves.
5. **Section A (4:30-7:20).** The messy Q1 folder and `_Q1_Answers.docx`. Do, paste a screenshot, or type. Details layout, sort by Date modified, add a column. The screenshot steps: do the task, Windows key + Shift + S, crop to the column headings and the sort arrow, paste under the question number. A written comparison with a fence: .png and .jpg, not about size.
   > Screen: Details layout chosen; sorted by Date modified, newest first; Snipping Tool selection around the headings and file list; pasted into `_Q1_Answers.docx`. Highlighter on the sort arrow.
6. **Sign-off.**

## cat12-27.2 Mark lines and Student_Screenshots (about 6 min)

**Goes:** after section `#screenshots` - the comment after `w27Screens`.
**The pupil can afterwards:** explain how the IEB memo's mark lines credit a partly right answer, and use Student_Screenshots for partial marks.
**Thumbnail:** tag `CAT · PAPER I`, title "When it *won't* work"

### Scenes

1. **Hook (0:00-0:30).** Hi, and welcome to BestLessons. Five minutes left, and the pivot table shows an error. Is that 5 marks gone?
   > Board: a pivot table with a red error; a clock; Clicky biting his nails.
2. **One line, one mark (0:30-2:10).** The memo as one long grid; a 5-mark formula written five times; the marker credits the lines that are right. Absolute references: often a line of their own.
   > Board: the grid drawn with five rows for one formula; ticks on four, a cross on the absolute line.
3. **The Comments column (2:10-3:30).** Building blocks accepted; IFS or nested IF; VLOOKUP or XLOOKUP; "accept any border"; "highlight is not shading". Where the question is exact, be exact.
   > Board: the Comments column filled in; highlighter on "must be shading".
4. **Student_Screenshots (3:30-5:20).** Question number; a cropped screenshot of the problem; a short explanation of what you tried and what went wrong. Not a second answer book: still leave your best attempt in the file.
   > Screen: a practice query that returns no records; its design grid snipped and pasted into Student_Screenshots.docx under "8.6" with one sentence typed.
5. **Sign-off.**

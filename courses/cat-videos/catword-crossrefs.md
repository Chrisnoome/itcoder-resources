## catword-23.1 Bookmarks and cross-references (about 8 min)

**Goes:** after the written question `wWhyCrossRef`, before the scenario
(the comment `// VIDEO catword-23.1`).
**The pupil can afterwards:** add a bookmark and go to it (Go To, a link to
a place in this document), insert a cross-reference to a heading, a
bookmark or a caption - its text, page number, label and number or
above/below - and update every field with Ctrl+A, F9.
**Thumbnail:** tag `CAT · WORD`, title "See page... *which* page?"

### Scenes

1. **Hook (0:00-0:40).** Hi, and welcome to BestLessons. "The meter readings
   are in Table 1 on page 2" - and the table is now on page 4. Nobody
   noticed until the moderator did.
   > Board: a signpost "Table 1 ->" pointing at an empty field, the table
   > walking off behind it; Clicky shrugging.
2. **A bookmark (0:40-2:00).** Select the caption; Insert > Bookmark; the
   name MeterTable (a letter first, no spaces); Add. File > Options >
   Advanced > Show bookmarks: the grey brackets.
   > Screen: each click; yellow highlighter on the name rules.
3. **Getting there (2:00-3:00).** Ctrl+G: Go to what: Bookmark; and Insert
   > Link > Place in This Document - Ctrl+click jumps.
4. **A cross-reference (3:00-5:00).** Type "on page " and stop; Insert >
   Cross-reference; Reference type: Bookmark; Insert reference to: Page
   number; MeterTable; Insert; Close. Click it: grey - a field. Then
   [table]: Table, Only label and number. Then [heading]: Heading, Heading
   text.
   > Screen: the Cross-reference box, each choice.
   > Board: a table of "Insert reference to" choices and what Word writes.
5. **Keeping them right (5:00-6:40).** Put a page break before How much
   water we use: the table moves; the reference still says 3. Ctrl+A, F9:
   it says 4. Updated before printing too. Alt+F9 shows the field codes.
   Delete the bookmark: "Error! Reference source not found."
   > Board: Clicky pressing a giant F9 key, numbers rearranging themselves.
6. **Sign-off.**

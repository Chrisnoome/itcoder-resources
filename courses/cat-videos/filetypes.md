# CAT 10 lesson 18: File types and extensions - videos

Lesson file: `AIPascalCourse/content/cattheory10/filetypes.php`. Two videos,
both mostly screen recordings in the VM. Everything said or shown here is
also in the lesson text (anchors in the tables below).

**Screen recordings:** the VM, Windows 11, Microsoft 365. Before recording,
make a folder `Documents\Fun Day` holding the ten files of the lesson's
scenario: `Entrants.accdb`, `Fun Day.docx`, `Highlights.mp4`, `index.html`,
`Logo.png`, `Notes.txt`, `Old entries.zip`, `Poster.pptx`, `Results.csv`,
`Theme song.mp3` (small real files of each type - the video opens some),
plus `Sponsors.rtf`. Do NOT make a fake `results.pdf.exe` in the VM - the
board shows that trick with the `hidden-extension` drawing. File name
extensions OFF at the start of 18.1.

## cat10-18.1 What the letters after the dot tell you (about 7 min)

**Goes:** at the end of section `#others` (the comment
`// VIDEO cat10-18.1`), before `#openwith` - by then the pupil has read every
extension the video names.
**The pupil can afterwards:** say what an extension is, switch extensions on,
explain the double-extension trick, and name the kind of file for the common
extensions (Office, text, pictures, sound, video, PDF, zip, exe).
**Thumbnail:** tag `CAT · FILES`, title "What's after the *dot*?"

### Scenes

1. **Hook (0:00-0:40).** Hi, and welcome to BestLessons. Gogo Dlamini gets
   Programme.pdf, Choir.mp3 and Bazaar.jpg on WhatsApp. "Why does every name
   have a full stop and letters at the end?" Those letters tell you what you
   are about to open.
   > Board: Gogo's phone with three file bubbles; highlighter on each
   > extension.
2. **The extension (0:40-1:40).** The part after the LAST full stop.
   Grade 10.Term 1.marks.xlsx - only .xlsx counts. Two jobs: tells you, tells
   Windows. Renaming .jpg to .docx changes nothing inside.
   > Board: the long name written out; the last full stop circled, yellow
   > band on .xlsx; a photo in a .docx costume, Word confused.
3. **Switching them on (1:40-2:40).** Windows hides them; in CAT you want
   them.
   > Screen: VM, Documents\Fun Day with extensions hidden (names without
   > extensions). Click View > Show > File name extensions. Every name now
   > shows its extension; highlighter sweeps down the list.
4. **The .pdf.exe trick (2:40-3:40).** results.pdf.exe shows as results.pdf
   when extensions are hidden - but it is a program. Two extensions or a
   .exe by e-mail or WhatsApp: stop and look.
   > Board: the `hidden-extension` drawing redrawn in marker; pink highlighter
   > on .exe; Clicky holding up a stop sign.
5. **Office files (3:40-4:50).** .docx Word document, .xlsx spreadsheet,
   .accdb database, .pptx presentation; .ppsx opens straight into the show;
   .doc, .xls, .mdb, .ppt before 2007.
   > Screen: VM, Details view of Documents\Fun Day. Hover each Office file;
   > highlighter on its extension and on its Type column entry.
6. **Text, pictures, sound and video (4:50-6:20).** .txt plain, .rtf with
   formatting, .csv rows with commas, .html a web page. .jpg photos, .png
   sharp and see-through, .gif animated. .mp3 sound only; .mp4 video with
   sound. .pdf looks the same everywhere; .zip packed and smaller; .exe a
   program.
   > Screen: VM. Double-click Notes.txt (Notepad opens; close). Right-click
   > Results.csv > Open with > Notepad: show the commas; close.
   > Board: a quick sorting tray - Picture / Sound / Video - with file cards
   > dropping in.
7. **Sign-off.**

## cat10-18.2 Open with, and saving as a PDF (about 6 min)

**Goes:** after the written question `w18Pdf`, at the end of section
`#saveas` (the comment `// VIDEO cat10-18.2`), before the scenario.
**The pupil can afterwards:** explain file association and default app; open
a file once in another program; change the default; save a document as a PDF
with Save As and with Export.
**Thumbnail:** tag `CAT · FILES`, title "Open it *your* way"

### Scenes

1. **Hook (0:00-0:30).** Hi, and welcome to BestLessons. Double-click a .docx
   and Word opens. How does Windows know?
   > Board: a .docx card going into a "list" book; Word's W coming out.
2. **File association (0:30-1:20).** Windows keeps a list: extension -
   program. Each line is a file association; the program is the default app.
   > Board: the `file-association` drawing redrawn; yellow band on
   > "default app".
3. **Open with, just once (1:20-2:30).** Thabo wants to edit Logo.png in
   Paint, not in Photos.
   > Screen: VM, Documents\Fun Day. Double-click Logo.png - Photos opens;
   > close it. Right-click Logo.png > Open with > Paint. Paint opens; close.
   > Double-click Logo.png again - still Photos.
4. **Change the default (2:30-3:30).** Right-click > Open with > Choose
   another app > the program > Always. Just once vs Always.
   > Screen: VM. Right-click Results.csv > Open with > Choose another app >
   > Notepad > Just once (do NOT click Always in the VM recording; show the
   > Always button with a highlighter band and say what it would do). Then
   > right-click Results.csv > Properties: point at Opens with and Change.
5. **Save As another type (3:30-4:50).** Lerato's CV: File > Save As >
   Browse; the Save as type list; PDF; Save. The .docx is still there.
   > Screen: VM. Open Fun Day.docx. File > Save As (or Save a Copy) > Browse.
   > Click the Save as type list; highlighter on PDF; choose it; type
   > Fun Day; Save. In File Explorer: Fun Day.docx and Fun Day.pdf side by
   > side.
6. **Export (4:50-5:30).** PowerPoint: File > Export > Create PDF/XPS. Why
   PDF: same everywhere, anyone can open it, hard to change, prints the same.
   Check the new file before sending.
   > Screen: VM. Open Poster.pptx. File > Export > Create PDF/XPS Document >
   > Create PDF/XPS > Publish. Show the PDF opening in the browser.
7. **Sign-off.**

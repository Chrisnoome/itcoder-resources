# CAT 10 lesson 17: Files, folders, drives and paths - videos

Lesson file: `AIPascalCourse/content/cattheory10/files.php`. Two videos: the
first is mostly a screen recording in File Explorer, the second mostly board.
Everything said or shown here is also in the lesson text (anchors in the
tables below).

**Screen recordings:** the VM, Windows 11, File Explorer opening on This PC
with recent files off (tutorial-videos.md). Before recording, make the
user `Thabo` (or rename the profile folder shown so that the address bar
reads `C:\Users\Thabo\Documents`) and create `Documents\CAT` with
`Notice.docx`, `Market Day poster.pptx` and a sub-folder `Term 1`;
`Documents\PAT`; a flash drive (a VHD mounted as E: with the label USB
Drive will do) holding `School\CAT\Market Day.pptx`. File name extensions on.

## cat10-17.1 Finding your way in File Explorer (about 7 min)

**Goes:** after the order question `o17OpenFolder`, at the end of section
`#explorer` (the comment `// VIDEO cat10-17.1` marks the place).
**The pupil can afterwards:** say what a file, folder, sub-folder, drive and
root folder are; name File Explorer's six parts; open a folder, go back and
go up; find a flash drive under This PC.
**Thumbnail:** tag `CAT · FILES`, title "Where *is* my file?"

### Scenes

1. **Hook (0:00-0:40).** Hi, and welcome to BestLessons. Thabo typed a notice
   for Market Day, clicked Save, typed Notice, and closed Word. Today he
   cannot find it. It isn't lost. He just never looked at where Word put it.
   > Board: Thabo at a laptop, a thought bubble with "???"; Clicky pointing
   > at the Save button.
2. **Saving (0:40-1:30).** While you type, your work is in RAM, which forgets
   when the power goes. Save copies it into a file on a drive. A file is one
   saved thing with a name.
   > Board: RAM as a whiteboard being wiped by a power cut; an arrow labelled
   > SAVE into a drive; yellow highlighter on "file".
3. **Folders (1:30-2:30).** The school bag: a file for each subject, dividers
   for Term 1 and Term 2, the sheets behind them. Sheets are files; subject
   files and dividers are folders and sub-folders. A folder holds no data of
   its own.
   > Board: the school bag opened up, labels FILE / FOLDER / SUB-FOLDER on
   > sticky notes.
4. **Drives (2:30-3:40).** C: the laptop's own drive; the next free letter
   for a flash drive; H: or S: the school's network drive on a server; a
   cloud drive such as OneDrive, syncing to every device. The root folder is
   the top of a drive: C:\.
   > Board: the laptop, a flash drive, the school server down a cable, a
   > cloud; each gets its letter on a sticky note.
5. **File Explorer's parts (3:40-4:50).** Windows key + E. The command bar,
   address bar, search box, navigation pane, file list and status bar, each
   circled as it is named.
   > Screen: VM. Press Windows key + E (key-press overlay). Hover over each
   > part in turn while a yellow highlighter band appears on its name in a
   > caption: command bar, address bar, search box, navigation pane, file
   > list, status bar.
6. **Opening a folder (4:50-6:00).** Click Documents in the navigation pane.
   Double-click CAT. Look at the address bar: Documents > CAT. Back arrow;
   Up arrow; click "Documents" in the address bar to jump back.
   > Screen: VM. Click Documents (navigation pane). Double-click CAT. Zoom on
   > the address bar, highlighter on "CAT". Click the Back arrow; click
   > Forward; click Up (Alt + Up shown as overlay); double-click CAT again;
   > click "Documents" in the address bar.
7. **A flash drive (6:00-6:40).** Click This PC; the drives are listed;
   double-click USB Drive (E:); you are in its root folder, E:\.
   > Screen: VM. Click This PC. Double-click USB Drive (E:). Click in the
   > empty part of the address bar: it shows E:\.
8. **Sign-off.**

## cat10-17.2 Writing down where a file is (about 6 min)

**Goes:** after the typed question `t17WriteSpec`, at the end of section
`#paths`.
**The pupil can afterwards:** draw a folder tree, give reasons for a folder
structure, split a file specification into drive, path, file name and
extension, write one, and see a file's path in File Explorer.
**Thumbnail:** tag `CAT · FILES`, title "Directions to a *file*"

### Scenes

1. **Hook (0:00-0:30).** Hi, and welcome to BestLessons. "It's in the
   folder." Which folder? Today you learn to give directions to a file that
   nobody can get wrong.
   > Board: two stick figures, one pointing vaguely; Clicky puzzled with "?".
2. **The tree (0:30-1:40).** The root at the top; folders one level down;
   sub-folders further down. An upside-down tree: a hierarchy. Why bother:
   find quickly, nothing lost or saved twice, back up one folder, share one
   folder, others can find things.
   > Board: the folder tree drawn level by level, from C:\ down to
   > Documents\CAT\Notice.docx; the five reasons as ticks on a sticky note.
3. **Directions to a house (1:40-2:20).** Main road, Church Street, number 12.
   Directions to a file: the drive, then each folder down the tree.
   > Board: a street map turning into the folder tree.
4. **The four parts (2:20-3:40).** C:\Users\Thabo\Documents\CAT\Notice.docx:
   drive C:, path \Users\Thabo\Documents\CAT\, file name Notice, extension
   .docx. Backslash between folders; a Mac and the web use /.
   > Board: the specification written large; each part gets its highlighter
   > (yellow drive, pink path, blue name) and a label; the extension circled.
5. **Writing one, step by step (3:40-4:40).** H:, add \, add CAT\PAT\, add
   Phase 1.docx.
   > Board: the four steps building the line left to right.
6. **Seeing a path (4:40-5:40).** Click the empty part of the address bar -
   the breadcrumbs become C:\Users\Thabo\Documents\CAT. Esc. Right-click
   Notice.docx, Copy as path; paste into Notepad.
   > Screen: VM. In Documents\CAT, click in the empty space at the right of
   > the address bar; highlighter band on the path text; press Esc.
   > Right-click Notice.docx > Copy as path. Open Notepad (Start, type
   > Notepad, Enter), Ctrl + V. Highlighter on the pasted line.
7. **Sign-off.**

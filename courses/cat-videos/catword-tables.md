# catword lesson 7: Tables - videos

Lesson: `content/catword/tables.php` (Grade 10). Screen recordings in the CAT
VM (Word 365), starting from SaturdaySales.docx (G:\My Drive\CAT\Word) and a
blank document. Never show the title bar's account. Board scenes in the CAT
marker style with Clicky; yellow highlighter on what is talked about.

## catword-07.1 Making a table (about 7 min)

**Goes:** after the simulation `simMergeTitle` in section `#merge` (the
comment `// VIDEO catword-07.1`).
**The pupil can afterwards:** insert a table from the grid or the Insert
Table dialog box, move round it with Tab and Shift+Tab, add a row with Tab,
select rows, columns and the table, insert and delete rows and columns, merge
and split cells, and change cell sizes with AutoFit and Distribute.
**Thumbnail:** tag `CAT · WORD`, title "Rows, columns, *cells*"

### Scenes

1. **Hook (0:00-0:40).** Hi, and welcome to BestLessons. Mr Botha's prices
   lined up with spaces zigzag down the page.
   > Board: the zigzag list; Clicky drawing a grid over it.
2. **Rows, columns, cells (0:40-1:30).** A grid; a 3x6 table is 3 columns
   and 6 rows.
   > Board: a school timetable; highlighter on one row, one column, one cell.
3. **Insert a table (1:30-2:40).** Insert, Table, the square 3 across and 6
   down. Insert Table... for bigger ones.
   > Screen: exactly that; the Table Design and Layout tabs appear.
4. **Typing (2:40-3:40).** Tab, Shift+Tab, arrows; Enter makes the cell
   taller; Tab in the last cell adds a row.
   > Screen: type Item, Price (R), Number sold and the five items; Tab at the end.
5. **Rows and columns (3:40-5:30).** Select a row, a column, the table (the
   move handle). Insert Above / Below / Left / Right; Delete; Height, Width,
   AutoFit, Distribute.
6. **Merge and split (5:30-6:40).** Insert a row above, type the title,
   select the row, Layout, Merge Cells; Split Cells; Split Table.
7. **Sign-off.**

## catword-07.2 Formatting a table and its data (about 7 min)

**Goes:** after the written question `w7WhyTable` in section `#data` (the
comment `// VIDEO catword-07.2`).
**The pupil can afterwards:** apply a table style and its options, add
borders and shading, align and turn text in cells, repeat a header row, show
gridlines, sort a table, total and average a column with a formula (and
update it with F9), and convert a table to text.
**Thumbnail:** tag `CAT · WORD`, title "A table that *adds up*"

### Scenes

1. **Table Design (0:00-2:00).** Table Styles gallery: Grid Table 4 -
   Accent 1; Header Row, Banded Rows; Shading; Borders and the Border
   Painter.
   > Screen: Mr Botha's table.
2. **Layout tab extras (2:00-3:30).** The nine alignment buttons (numbers on
   the right); Text Direction; Cell Margins; Repeat Header Rows on a
   three-page class list; View Gridlines on a table with No Border.
   > Board: a printout with no gridlines - "they never print".
3. **Sort (3:30-4:30).** Select the item rows, Sort, Sort by Item,
   Ascending, Header row.
4. **Formulas (4:30-6:00).** The Total row: Layout, Formula, =SUM(ABOVE),
   OK - 215. =AVERAGE(ABOVE). Change 60 to 70: still 215; select, F9: 225.
   > Board: Word table vs Excel sheet - "Lots of sums? Excel."
5. **Convert to Text (6:00-6:40).** Commas; and Convert Text to Table back.
6. **Sign-off.**

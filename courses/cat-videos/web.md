## cat10-25.1 The Web is not the Internet (about 7 min)

**Goes:** after the IEB section "More kinds of websites, and shopping online" - the comment before section `#urls`.
**The pupil can afterwards:** say how the Web differs from the Internet; tell a web page, website, home page, hyperlink, web server and browser apart; name blogs, vlogs, wikis, social networks and web apps with an example; (IEB) name the other kinds of website and the online services.
**Thumbnail:** tag `CAT · THE WEB`, title "The Web is *not* the Internet"

### Scenes

1. **Hook (0:00-0:40).** Hi, and welcome to BestLessons. Gogo: "The Internet is broken - the SASSA page won't open." Thabo sends her a voice note; it arrives. Her Internet is fine. The website is down.
   > Board: Gogo's phone with a broken page; a voice note arriving beside it. Clicky with a "!".
2. **Roads and taxis (0:40-1:50).** The Internet is the roads. The Web is one of the things that travel on them - like the taxis: web pages, stored on computers everywhere, linked together, opened in a browser. WhatsApp, e-mail, calls and games use the roads too, but they are not the Web.
   > Board: the web-on-internet drawing; a road with taxis labelled "the Web" and other vehicles labelled e-mail, WhatsApp, calls. Yellow highlighter on "network" and "service".
3. **Page, site, home page, link (1:50-3:30).** One at a time: a web page (one document - the sports fixtures), a website (all the school's pages), the home page (the main page, with the menu), a hyperlink (tap it, another page opens), the web server (stores the site), the browser (shows it). A website is like a book. Hover over a link to see where it really goes.
   > Board: the page-site-server drawing built part by part; a book beside it with "cover = home page".
4. **Kinds of websites (3:30-5:30).** Blog (weblog) and vlog; wiki (readers edit it - Wikipedia); social network (profiles, friends, posts); web application (a program in the browser - Google Docs, Microsoft 365, Google Drive, OneDrive) with its good and bad.
   > Board: four boxes, one per kind, each with a tiny example; then a web-app good/bad list with highlighter swipes.
5. **IEB: more kinds and e-commerce (5:30-6:40).** Portal, news, informational, business, educational, entertainment, advocacy, content aggregator, personal. E-commerce: shopping, banking, booking and reservations, EFT. (Say it is the IEB's list; everyone may watch.)
   > Board: the table's names as quick icons; a card being tapped for "EFT". Note: an "IEB" flag in the corner for this scene.
6. **Sign-off.**

## cat10-25.2 Reading a URL, and short links (about 6 min)

**Goes:** after section `#shorteners` - the comment after `w25ShortRisk`.
**The pupil can afterwards:** name the parts of a URL; read a domain name's ending (.za, .co.za, .gov.za, .ac.za, .org.za, .com); find the real domain name; say what a URL shortener does, why it is used and its risks.
**Thumbnail:** tag `CAT · THE WEB`, title "Read a *URL* like a pro"

### Scenes

1. **Hook (0:00-0:30).** Hi, and welcome to BestLessons. A message: "Claim your tax refund at www.sars.gov.za.tax-refund.co". Is that SARS?
   > Board: the address written out; Clicky squinting at it.
2. **The parts (0:30-2:20).** https://www.bothasbakery.co.za/menu/bread.html, left to right: the protocol (s = secure), the domain name (which site), the path with its folder, the file name. A ? adds extra information; a # jumps to a spot.
   > Board: the address written large, each part boxed and labelled as it is said; yellow highlighter on each part in turn.
   > Screen: Edge in the VM on bestlessons.co.za - hover over a link; the address appears at the bottom left. Highlighter band on it.
3. **Reading the ending (2:20-3:20).** .za South Africa (Zuid-Afrika); .co.za company, .gov.za government, .ac.za university, .org.za non-profit; .com no country. dha.gov.za is Home Affairs.
   > Board: a sticky note with the endings.
4. **The real domain name (3:20-4:10).** It ends at the first single / . Read its end first: tax-refund.co - not SARS. The real one ends in sars.gov.za.
   > Board: the url-lookalike drawing; pink highlighter on "tax-refund.co".
5. **URL shorteners (4:10-5:40).** A long Google Form link nobody can type from a poster. A shortener makes a short link that leads to the long one - the five steps (paste, get a code, share, tap, sent on). Why: short, fits an SMS, easy to type, counts clicks. Problems: hides where it goes, breaks if the service closes. A short link from a stranger is a sealed parcel from a stranger.
   > Board: a poster with a long scribbled link, then a short one; arrows for the five steps; Clicky with binoculars: "Where does it go?"
6. **Sign-off.**

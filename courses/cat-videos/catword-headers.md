# catword lesson 15: Headers, footers and page numbering - videos

Lesson: `content/catword/headers.php` (Grade 11). Screen recordings in the
CAT VM (Word 365), starting from History project.docx (G:\My
Drive\CAT\Word). Never show the title bar's account; paint out the Add-ins
group. Board scenes in the CAT marker style with Clicky; yellow highlighter
on what is talked about. Quick Parts is IEB (say so once: "the IEB names
Quick Parts; CAPS pupils use Document Info for the same fields").

## catword-15.1 Fields and a different first page (about 7 min)

**Goes:** after the quiz `q15OddEven`, before section `#numbers` (the
comment `// VIDEO catword-15.1`).
**The pupil can afterwards:** insert the date, author, file name and path
and title as fields, update them, and give a first page or odd and even
pages their own headers and footers.
**Thumbnail:** tag `CAT · WORD`, title "The footer that knows *where the file is*"

### Scenes

1. **Hook (0:00-0:40).** Hi, and welcome to BestLessons. A year later,
   Lerato holds her printed project and cannot find the file. The footer
   could have told her.
   > Board: a printout with a luggage tag "C:\...\History project.docx",
   > Clicky following a path of folders.
2. **Fields (0:40-3:00).** Double-click the top margin; Header & Footer >
   Date & Time (Update automatically), Document Info > Author, File Name,
   File Path, Document Title. Grey when clicked; F9 updates; Alt+F9 shows
   { FILENAME \p }.
   > Screen: the clicks above.
3. **Different First Page (3:00-4:40).** The cover shows a page number. Tick
   Different First Page: the label says First Page Header, the cover is
   empty, page 2 keeps its number.
4. **Odd and even (4:40-6:20).** A book printed on both sides: Different Odd
   & Even Pages; numbers on the right of odd pages, the left of even ones.
   > Board: an open book, Clicky pointing at the outside corners.
5. **Sign-off.**

## catword-15.2 Page numbers and sections with their own headers (about 8 min)

**Goes:** after the written question `w15FilePath`, before the IEB section
(the comment `// VIDEO catword-15.2`).
**The pupil can afterwards:** format page numbers (i, ii; Start at 1), break
the link between sections' headers, and (IEB) use Quick Parts.
**Thumbnail:** tag `CAT · WORD`, title "Page *i*, page *1*"

### Scenes

1. **Format Page Numbers (0:00-2:30).** Page Number > Format Page Numbers...:
   Number format i, ii, iii in section 1; Start at 1 in section 2; Continue
   from previous section.
   > Screen: History project.docx, footer of section 2.
2. **Same as Previous (2:30-5:00).** Each section's header is linked: type in
   section 2's and section 1 changes. Next; Link to Previous off; type The
   1976 Soweto Uprising; Previous to check section 1 is empty. Header and
   footer link separately; linking again.
   > Board: two train carriages with a chain marked "Link to Previous",
   > Clicky unhooking it.
3. **Quick Parts - IEB (5:00-7:00).** Insert > Quick Parts: AutoText (Save
   Selection to AutoText Gallery - Botha's Bakery's address), Document
   Property, Field... (FileName, NumPages), Building Blocks Organizer.
4. **Sign-off.**

# Presentations lesson 5: Running a slide show - videos

Lesson: `content/catpowerpoint/slideshow.php`. Screen recordings in the
**CAT VM `itcoder-cat`** (PowerPoint 365; Presenter View on one screen with
Alt+F5), board scenes in the CAT marker style with Clicky.

## catpowerpoint-05.1 Running the show and speaker notes (about 6 min)

**Goes:** after the written question in section `#notes` (before `#setup`).
**The pupil can afterwards:** start a show from the beginning or the current slide, move around in it with the keys, and use speaker notes and Presenter View.
**Thumbnail:** tag `CAT · POWERPOINT`, title "*Showtime*"

### Scenes

1. **Hook (0:00-0:30).** Hi, and welcome to BestLessons. When the buttons are
   second nature, you stop thinking about PowerPoint and talk to people.
2. **Starting (0:30-1:30).** F5 from the beginning; Shift+F5 from here; the
   Slide Show button on the status bar.
   > Screen: Shift+F5 on slide 3; Esc.
3. **Moving around (1:30-3:00).** Next: click, Space, Enter, right arrow, N.
   Back: Backspace, left arrow, P. A number and Enter. B for black, W for
   white. Esc.
   > Screen: each key in a running show; the key shown large on screen as it is pressed.
4. **Speaker notes (3:00-4:30).** The Notes pane: "Rusks: R45 a packet".
   Notes Page view. Short slides, full notes.
   > Screen: type the note; View > Notes Page.
5. **Presenter View (4:30-5:40).** The slide, your notes, the next slide, a
   timer - the audience sees only the slide.
   > Screen: Alt+F5; point at each part.
6. **Sign-off.**

## catpowerpoint-05.2 A show that runs by itself, printing and saving (about 7 min)

**Goes:** after the last question in section `#output` (before the study block).
**The pupil can afterwards:** set up a kiosk show with timings, hide a slide, add a hyperlink, print handouts and notes pages, and save as a PDF, a show or a video.
**Thumbnail:** tag `CAT · POWERPOINT`, title "A show with *no one* clicking"

### Scenes

1. **Hook (0:00-0:30).** Hi, and welcome to BestLessons. Mr Botha's TV must
   run all day, round and round.
   > Board: the bakery TV with a loop arrow round it.
2. **Set Up Slide Show (0:30-2:00).** The three show types; Browsed at a
   kiosk ticks Loop continuously until 'Esc'. Show slides From - To; Using
   timings. Rehearse Timings. Hide Slide.
   > Screen: the Set Up Slide Show box; then Rehearse Timings for two slides.
3. **Links (2:00-3:20).** Select "prices", Ctrl+K, Place in This Document,
   slide 9. A web link. Action buttons.
   > Screen: make both links, click them in the show.
4. **Printing (3:20-4:40).** File > Print: Full Page Slides, Notes Pages,
   Outline, Handouts (3 per page with lines). Grayscale.
   > Screen: the Print page; change the setting and watch the preview.
5. **Saving (4:40-6:30).** File > Export > Create PDF/XPS; Save As
   PowerPoint Show (.ppsx); Create a Video (.mp4). Which for whom. (CAPS
   names the show and the video; worth knowing.)
   > Screen: each of the three; double-click the .ppsx to show it opening as a show.
6. **Sign-off.**

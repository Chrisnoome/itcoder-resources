# catword lesson 24: Mail merge from any source - videos

Lesson: `content/catword/mergesources.php` (Grade 12). Screen recordings in
the CAT VM (Word 365, Excel 365), starting from Farewell invitation.docx
and Farewell guests.csv (G:\My Drive\CAT\Word), with the same guest list
as a Word table and an Excel sheet in the same folder. Never show the
title bar's account, and no real e-mail addresses (the list uses
@bestlessons.co.za). Board scenes in the CAT marker style with Clicky;
yellow highlighter on what is talked about. Recap Grade 11's mail merge in
one sentence; never teach it again. Forms are IEB Grade 12 - say so once.
Never "in the exam".

## catword-24.1 Choosing a data source (about 7 min)

**Goes:** after the match `mSources`, before the IEB section "Answers from
an online form" (the comment `// VIDEO catword-24.1`).
**The pupil can afterwards:** say what makes a good data source, connect a
Word table, an Excel sheet, an Access table, a CSV file or Outlook
contacts, and answer what Word asks about each.
**Thumbnail:** tag `CAT · WORD`, title "One letter, *five* kinds of lists"

### Scenes

1. **Hook (0:00-0:40).** Hi, and welcome to BestLessons. Ms Naidoo's
   farewell list is in five places: Word tables, Excel, a CSV export,
   Outlook and an online form.
   > Board: five folders on a desk, Clicky juggling them.
2. **Grade 11 in one sentence (0:40-1:10).** Main document plus data
   source; the Mailings tab left to right.
3. **A good list (1:10-2:30).** Field names in row 1, one person per row,
   one detail per column, no blank or total rows; the "Dear FAREWELL
   PAYMENTS 2026" letter.
   > Board: a spreadsheet with a title row crossed out in red; yellow
   > highlighter on row 1's field names.
4. **Connecting (2:30-4:00).** Mailings > Select Recipients > Use an
   Existing List > All Data Sources; the Word table (nothing asked); the
   Excel workbook (Select Table: Sales$, First row of data contains column
   headers); the CSV (Header Record Delimiters: comma, Enter).
   > Screen: each source in turn, the box Word shows.
5. **Access and Outlook (4:00-5:20).** An Access table or query in Select
   Table; Choose from Outlook Contacts; Type a New List.
6. **Changing the data (5:20-6:20).** Edit Recipient List > Data Source >
   Edit for a Word or Access list; Excel and CSV in Excel; a moved list must
   be selected again.
7. **Sign-off.**

## catword-24.2 Filtering and finishing the merge (about 7 min)

**Goes:** after the written question `wFilterNotUntick`, before the
scenario (the comment `// VIDEO catword-24.2`).
**The pupil can afterwards:** choose records with a filter of more than
one row (And, Or), use an e-mail list as the source, and fix a merge that
goes wrong; IEB: merge the answers of an online form.
**Thumbnail:** tag `CAT · WORD`, title "Only the ones who *paid*"

### Scenes

1. **Hook (0:00-0:30).** Eight matrics, five have paid: five letters, not
   eight.
2. **Edit Recipient List (0:30-1:30).** The tick boxes; untick one; Sort...
3. **Filter (1:30-3:30).** Filter... (the Query Options box, Filter Records): Paid, Equal to, Yes. Then And: Class
   Equal to 12C (only 12Cs who paid). Then Or: Class 12A Or Class 12B. The
   And that gives nothing.
   > Board: a Venn diagram - And is the overlap, Or is both circles; yellow
   > highlighter on the overlap.
   > Screen: the Filter and Sort box.
4. **More than one row (3:30-4:30).** The match from the lesson: 12A And
   paid; 12A Or 12C; Not equal to Yes; an Access query that has chosen and
   sorted the records already.
5. **An e-mail list (4:30-5:40).** Grade 11 merged to e-mail; what is new
   is the list: an Email column, or Outlook contacts; in Merge to E-mail, To
   is that field. Finish & Merge > Edit Individual Documents for the CSV
   letters, saved as the merged document.
6. **IEB: an online form (5:40-6:30).** A Microsoft Forms result in Excel:
   shorten the question headings to field names; connect it like any sheet.
   > Board: paper reply slips blowing away, one tidy spreadsheet arriving.
7. **When it goes wrong (6:30-7:00).** «FirstName» in every letter; a
   TOTAL letter; the moved list.
8. **Sign-off.**

# catword lesson 10: Hyperlinks, help and fixing problems - videos

Lesson: `content/catword/integration.php` (Grade 10). Screen recordings in
the CAT VM (Word 365 and Excel 365), starting from SalesReport.docx and
SaturdaySales.xlsx (G:\My Drive\CAT\Word). Never show the title bar's
account - the Search box sits in the title bar, so show it only in a crop
that leaves the account out. Board scenes in the CAT marker style with
Clicky; yellow highlighter on what is talked about.

## catword-10.1 Hyperlinks and copying between programs (about 7 min)

**Goes:** after the quiz `q10KeepText` in section `#paste` (the comment
`// VIDEO catword-10.1`).
**The pupil can afterwards:** make a link to a web page, a file and an
e-mail address, follow, edit and remove it, keep linked files together, copy
cells from Excel into Word and choose a Paste Option.
**Thumbnail:** tag `CAT · WORD`, title "Word *joins* the world"

### Scenes

1. **Hook (0:00-0:40).** Hi, and welcome to BestLessons. Half the class
   cannot find the website on Ms Naidoo's notice.
   > Board: Clicky as a chain link between a page and a globe.
2. **A link to a web page (0:40-2:20).** Select BestLessons website; Insert,
   Link (Ctrl+K); Address https://bestlessons.co.za; OK. Ctrl+click to
   follow; right-click Edit Link / Remove Link. Typing an address makes a
   link.
3. **A link to a file (2:20-3:40).** Existing File or Web Page, the folder,
   SaturdaySales.xlsx. Move the file: the link breaks.
   > Board: a link arrow pointing at an empty shelf.
4. **Excel into Word (3:40-5:40).** In Excel select A1:C7, Ctrl+C; in Word
   click the empty line, Ctrl+V. The Paste Options button: Keep Source
   Formatting, Use Destination Styles, Picture, Keep Text Only. A web
   paragraph with Keep Text Only. A pasted copy does not update.
5. **Sign-off.**

## catword-10.2 Finding help and fixing problems (about 7 min)

**Goes:** after the written question `w10Help` in section `#problems` (the
comment `// VIDEO catword-10.2`).
**The pupil can afterwards:** find help with ScreenTips, the Search box, F1,
the Help pane and online FAQs, and find and fix the common Word problems.
**Thumbnail:** tag `CAT · WORD`, title "When Word *goes wrong*"

### Scenes

1. **Help (0:00-2:30).** Hover a button: the ScreenTip. Alt+Q, "watermark",
   click the command. F1, the Help pane, a search. Microsoft's support site
   and its FAQs; check the version.
   > Screen: a crop that keeps the account out of the picture.
2. **Find the cause first (2:30-3:20).** Show/Hide ¶ and the status bar.
   > Board: Clicky with a magnifying glass over a ¶ mark.
3. **The problems (3:20-6:20).** Ribbon gone (double-click a tab,
   Ctrl+F1); a gap (empty ¶ marks); CAPS LOCK; Overtype (the Insert key);
   Protected View (Enable Editing); Recover Unsaved Documents; pasted
   formatting (Keep Text Only, Clear All Formatting); the wrong language;
   zoom; the printer.
   > Screen: each one made to happen, then fixed.
4. **Save often (6:20-6:40).** Ctrl+S; the cloud.
5. **Sign-off.**

## catword-13.1 Your own bullets and numbers (about 7 min)

**Goes:** after the match `m13Numbers`, before section `#multilevel` (the
comment `// VIDEO catword-13.1`).
**The pupil can afterwards:** define a bullet (symbol, picture, font colour
and size), define a number format (Rule 1:), and start a list at any number.
**Thumbnail:** tag `CAT · WORD`, title "Ticks, not *dots*"

### Scenes

1. **Hook (0:00-0:40).** Hi, and welcome to BestLessons. "There are only 11
   types of people..." - II is two. Numbers can look many ways, and Word
   lists can use them all.
   > Board: 1, i, I, a, A written in marker, Clicky juggling them.
2. **Define New Bullet (0:40-2:40).** Select the three things to bring;
   Bullets arrow > Define New Bullet...; Symbol... (Wingdings, the tick);
   Font... (Dark Red); OK. Only the bullet changes colour.
   > Screen: the clicks above; yellow highlighter on Symbol, Picture, Font.
3. **Define New Number Format (2:40-4:30).** Numbering arrow > Define New
   Number Format: Number style (1, i, A), Number format - type Rule and a
   space before the grey number and a colon after it; never delete the grey
   number; Alignment right.
4. **Set Numbering Value (4:30-6:30).** The judging criteria must be rules 5
   to 8: right-click the number 1 > Set Numbering Value... > Set value to 5.
   Continue from previous list, Restart at 1 and Continue Numbering compared.
5. **Sign-off.**

## catword-13.2 Numbered headings, spacing and drop caps (about 8 min)

**Goes:** after the written question `w13Typed`, before the scenario (the
comment `// VIDEO catword-13.2`).
**The pupil can afterwards:** number a document's headings with a multilevel
list linked to the heading styles, set exact spacing and tab stops, and add a
drop cap.
**Thumbnail:** tag `CAT · WORD`, title "Rule *2.1* - numbered by Word"

### Scenes

1. **Hook (0:00-0:30).** "See rule 2.1" must mean one thing to everyone.
2. **Multilevel lists (0:30-3:30).** Tab and Shift+Tab move an item down and
   up a level. Outline numbering: heading styles first, then Multilevel
   List > the list with Heading 1 and Heading 2 beside its numbers. Add a
   heading (Safety) - the numbers move up. Define New Multilevel List, Link
   level to style.
   > Screen: Science expo.docx, the clicks above.
   > Board: a ladder 1, 1.1, 1.1.1, Clicky climbing down with Tab.
3. **Spacing, exactly (3:30-5:30).** Paragraph box: Multiple 1.15, At least
   (a big word gets room), Exactly (a big word is cut off); Before/After in
   points; Don't add space between paragraphs of the same style. The Tabs
   box: position, alignment, leader, Set, Clear All.
4. **A drop cap (5:30-7:00).** Insert > Drop Cap > Dropped; Drop Cap Options
   (font, lines to drop 3, distance). One per article.
   > Screen: the E of Every dropping beside three lines.
5. **Sign-off.**

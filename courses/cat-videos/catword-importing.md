# catword lesson 19: Text and data from other files - videos

Lesson: `content/catword/importing.php` (Grade 11). Screen recordings in the
CAT VM (Word 365 and Excel), starting from a new document, Price list
heading.rtf and Bakery prices.csv (G:\My Drive\CAT\Word). Never show the
title bar's account; paint out the Add-ins group. Board scenes in the CAT
marker style with Clicky; yellow highlighter on what is talked about. Table
formulas beyond SUM and AVERAGE are CAPS: say so once.

## catword-19.1 Text, csv and rtf files into Word (about 7 min)

**Goes:** after the quiz `q19Columns`, before section `#paste` (the comment
`// VIDEO catword-19.1`).
**The pupil can afterwards:** open or insert .txt, .rtf and .csv files, and
turn comma-separated lines into a table.
**Thumbnail:** tag `CAT · WORD`, title "Commas into a *table*"

### Scenes

1. **Hook (0:00-0:40).** Hi, and welcome to BestLessons. The till exports a
   .csv, the accountant sends an .rtf, the opening times are a .txt - one
   price list, no retyping.
   > Board: three envelopes marked .txt, .rtf, .csv sliding into one Word
   > page; Clicky catching them.
2. **The three formats (0:40-2:00).** Characters only; basic formatting;
   rows with commas. Opening one: File > Open > All Files; the File
   Conversion box; then Save As a Word Document.
3. **Text from File (2:00-3:40).** Insert > the Object arrow > Text from
   File... > Price list heading.rtf (its heading arrives formatted); again
   for Bakery prices.csv (All Files).
   > Screen: the clicks above.
4. **Convert Text to Table (3:40-5:40).** Select the seven lines; Insert >
   Table > Convert Text to Table...: Separate text at Commas; the number of
   columns; OK. And back: Convert to Text.
5. **Sign-off.**

## catword-19.2 Paste Special, links and Find and Replace (about 8 min)

**Goes:** after the quiz `q19Similar`, before the scenario (the comment
`// VIDEO catword-19.2`).
**The pupil can afterwards:** paste in a chosen form, link Excel data so it
updates, (CAPS) use COUNT, MAX and MIN in a table, and use Find and Replace's
options and the Editing group.
**Thumbnail:** tag `CAT · WORD`, title "Paste *link*: prices that update"

### Scenes

1. **Paste Special (0:00-2:30).** Copy the prices in Excel; Ctrl+Alt+V:
   Excel Worksheet Object (embedded), Formatted Text, Unformatted Text,
   Picture; Paste link. Change a price in Excel, Update Link in Word.
   File > Info > Edit Links to Files.
   > Board: a Word page and an Excel sheet joined by a chain (link) and,
   > beside them, a photocopy (embedded).
2. **Table formulas - CAPS (2:30-3:40).** Table Layout > Formula: =MAX(B2:B7),
   =MIN(ABOVE), =COUNT(ABOVE), =SUM(ABOVE)/COUNT(ABOVE); Number format; F9.
3. **Find and Replace: More (3:40-6:00).** Ctrl+H, More >>: Match case and
   Find whole words only (Choc to Chocolate); wildcards ? and *; Format;
   Special ^p and ^t (^p^p to ^p).
   > Screen: the box with More open.
4. **Editing group and AutoCorrect (6:00-7:20).** Go To (Ctrl+G); Select All
   Text With Similar Formatting; AutoCorrect Options: bbk becomes Botha's
   Bakery.
5. **Sign-off.**

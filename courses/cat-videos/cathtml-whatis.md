## cathtml-01.1 Your first web page in Notepad++ (about 8 min)

**Goes:** after section `#save` (the comment `// VIDEO cathtml-01.1`).
**The pupil can afterwards:** say what HTML is and what a tag is, type a
small page in Notepad++, save it as .html in the right folder, open it in a
browser, and see a change with save-and-refresh.
**Thumbnail:** tag `CAT · HTML`, title "Your *first* web page"

### Scenes

1. **Hook (0:00-0:40).** Hi, and welcome to BestLessons. Mr Botha of Botha's
   Bakery wants a web page, and Thabo is going to make it - for koeksisters.
   Under all the colours, a web page is just a file of text. Today you make
   one.
   > Board: Clicky holding a plate of koeksisters next to a laptop.
2. **What HTML is (0:40-2:00).** HyperText Markup Language, one word at a
   time: text with links; marks that say what each part is; words and rules
   a browser understands. Ms Naidoo's red pen: her marks say "heading" and
   "bold" without changing the words. The browser reads the marks and draws
   the page - rendering. HTML is not a programming language.
   > Board: a paragraph of text marked up in red pen ("heading", "bold"); then the same text drawn as a page.
3. **Tags (2:00-3:20).** Angle brackets; an opening tag switches on, the
   closing tag - same name, forward slash - switches off; what is between
   gets the effect. `<h1>Howzit</h1>` piece by piece. Lower case. The slash
   leans forward. br and hr have no closing tag (lesson 3).
   > Board: `<h1>Howzit</h1>` with the three parts highlighted one by one; a wrong `<h1>Bakery<h1>` crossed out.
4. **Notepad++ (3:20-4:40).** Open Notepad++. Why not Word: a .docx is not a
   web page, and Word makes curly quotes. Type the nine-line page (html,
   head, title, body, h1, p) - the tags turn blue only once it is saved as
   HTML.
   > Screen: Start > Notepad++; File > New; type the page from the lesson's first figure, slowly.
5. **Save it (4:40-6:00).** File > Save As; go to My Drive > CAT > HTML (make
   the folder if it is not there); File name botha.html; Save as type Hyper
   Text Markup Language file; Save. The tags turn blue. Mention Notepad: Save
   as type All files, or it may become botha.html.txt.
   > Screen: the Save As dialog as in the lesson's figure; yellow highlighter on File name and Save as type. Hide the folders pane (it shows the account name).
6. **Open it and change it (6:00-7:30).** File Explorer > the HTML folder >
   double-click botha.html: Edge opens it; the title on the tab, the heading
   and paragraph on the page. Change the heading in Notepad++; Edge still
   shows the old one. Ctrl+S, click Edge, F5 - there it is. Change, save,
   switch, refresh.
   > Screen: two windows side by side; the change made, the browser not changing, then Ctrl+S and F5.
   > Board: a loop of four arrows - change, save, switch, refresh.
7. **Sign-off.** In the lesson: the HTML box, two tries, and Thabo's first
   page to fix.

# catword lesson 20: Templates, forms and sharing - videos

Lesson: `content/catword/templates.php` (Grade 11). Screen recordings in the
CAT VM (Word 365), starting from Camp form.docx (G:\My Drive\CAT\Word).
Never show the title bar's account (Backstage and the Share pane show it -
crop or blur); paint out the Add-ins group. Board scenes in the CAT marker
style with Clicky; yellow highlighter on what is talked about. Legacy form
fields are CAPS: say so once.

## catword-20.1 Templates and a form (about 8 min)

**Goes:** after the written question `w20Form`, before section `#printing`
(the comment `// VIDEO catword-20.1`).
**The pupil can afterwards:** start a document from a template, save a
template, build a form with content controls (and, CAPS, legacy form
fields), and protect it for filling in.
**Thumbnail:** tag `CAT · WORD`, title "A form nobody can *mess up*"

### Scenes

1. **Hook (0:00-0:40).** Hi, and welcome to BestLessons. Every year someone
   types over the heading of the camp form.
   > Board: a form with scribbles everywhere, then a clean one with grey
   > boxes; Clicky with a padlock.
2. **Templates (0:40-2:30).** File > New, Personal. F12, Save as type Word
   Template (*.dotx), Custom Office Templates. Opening it gives Document1;
   the template stays clean. File > Open to change it.
   > Board: a cookie cutter and a row of biscuits.
3. **Content controls (2:30-5:00).** File > Options > Customize Ribbon >
   Developer. Plain Text after Pupil's name and Class, Date Picker, Drop-Down
   List (Properties > Add Yes, No), Check Box. Design Mode for the
   placeholders.
   > Screen: the clicks above.
4. **Legacy form fields - CAPS (5:00-6:00).** Developer > Legacy Tools: Text,
   Check Box and Drop-Down Form Fields; double-click for options.
5. **Protect (6:00-7:30).** Restrict Editing: Allow only this type of
   editing - Filling in forms; Yes, Start Enforcing Protection; Tab from box
   to box; Stop Protection.
6. **Sign-off.**

## catword-20.2 Printing, PDF and sharing (about 6 min)

**Goes:** after the typed question `t20Printer`, before the scenario (the
comment `// VIDEO catword-20.2`).
**The pupil can afterwards:** print a page range, odd or even pages, several
pages per sheet and a draft; make a PDF with options; share a document.
**Thumbnail:** tag `CAT · WORD`, title "Print *exactly* what you need"

### Scenes

1. **Printing (0:00-2:30).** Ctrl+P: Copies and Collated; Pages 1-3, 5;
   Only Print Odd Pages then even; Pages per sheet 4; Printer Properties
   quality; Microsoft Print to PDF.
   > Screen: the Print screen (crop the account).
2. **Export to PDF (2:30-3:40).** File > Export > Create PDF/XPS: Options -
   page range, bookmarks from headings; Optimize for Minimum size.
3. **Sharing (3:40-5:30).** Share: with people (Can edit / Can view, file in
   the cloud), Copy link, Send a copy (Word or PDF). Present Online has been
   retired. Careful with Can edit links.
   > Board: one file in a cloud with two arrows to two houses (Thabo,
   > Lerato), versus two copies being e-mailed back and forth.
4. **Sign-off.**

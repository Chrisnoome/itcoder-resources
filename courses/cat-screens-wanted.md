# CAT Theory: screens and simulations wanted

From the Managing files chapter (CAT Theory Grade 10, lessons 17-20), 6 October 2026. Capture in the video VM (tools/sim-screens, VM first), Windows 11. Nothing here is built yet.


These lessons describe steps in words (no new screenshots, per the brief).
In order of value - each would be a `simulation` (real Windows 11 screens,
one step each) unless noted:

1. **Move by file type** (the IEB's favourite task): Details view, Ctrl +
   click four .docx files, Ctrl + X, open Docs, Ctrl + V. (`managefiles`
   `#selecting` / `#copymove`)
2. **Zip and extract**: right-click a folder > Compress to > ZIP File, name
   it; right-click the zip > Extract All > Extract. (`#compress`)
3. **Sort**: View > Details; Sort > Date modified; Sort > Descending.
   (`#views`)
4. **Restore from the Recycle Bin**: open it, select, Restore the selected
   items. (`#delete`)
5. **New folder and rename**: New > Folder, type, Enter; select, F2, type,
   Enter. (`#create`, `#rename`)
6. **Show extensions / hidden items**: View > Show > File name extensions
   (`filetypes#showing`); View > Show > Hidden items (`properties#attributes`).
7. **Open with**: right-click > Open with > Paint; and Choose another app >
   Always. (`filetypes#openwith`)
8. **Desktop shortcut**: right-click > Show more options > Send to > Desktop
   (create shortcut). (`#shortcuts`)
9. **Properties**: Alt + Enter on a file; tick Read-only; OK. And adding
   the Date created column (right-click a heading). (`properties`)
10. **Search with a wildcard** (IEB): Ctrl + E, *.docx, Enter.
11. Real screenshots for the picture questions: a real Windows 11 File
    Explorer for a labelpic (to replace the drawn `pic-l24-explorer.svg`),
    a real Properties window (General tab) for a hotspot or labelpic (to
    replace or add to `identify-l19`), the Save As box with the Save as
    type list open (`filetypes#saveas`), and the Replace or Skip Files box
    (`managefiles#copymove`).
